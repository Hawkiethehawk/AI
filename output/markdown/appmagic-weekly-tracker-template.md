## 四、数据口径说明

| 字段 | 说明 |
|------|------|
| 排名 | AppMagic **Top Free** 榜单（下载量排名），可切换日/周/月粒度；推荐用 **周粒度** |
| Tag 路径 | 用 AppMagic 的 Tags 侧边栏 Drill-down：Grade 1 → 2 → 3 |
| 国家分布 | 在 App Detail 页 → **Downloads by Country**（免费版可见 Top 5 下载国） |
| 排名稳定性 | 用 AppMagic 的排名趋势图观察是否连续 4 周+ 稳在 Top 50 |
| 新品定义 | 首次进入 Top Free 前 50-100 的产品 |
| 关键位移 | 周环比 ↑↓ ≥5 位 |
