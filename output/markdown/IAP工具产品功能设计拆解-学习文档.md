# 工具产品功能设计拆解：IAP + IAA 双变现视角

> 从产品功能出发，标注每个功能的广告触发点和付费触发点。不谈策略，只看功能设计。

---

## 一、功能全景：三层 × 双变现

所有功能按变现角色分三层。每层同时承载 IAA（广告）和 IAP（付费）两个变现路径。

```
钩子层（免费好用，留住用户）
  ├── IAA：广告曝光的基础土壤（DAU = 广告库存）
  └── IAP：付费转化的用户池（DAU = 付费漏斗顶部）

感知层（让用户看到"更好"的选择）
  ├── IAA：广告位天然嵌入操作流
  └── IAP：灰显/限制/对比，埋下付费动机

转化层（变现事件触发）
  ├── IAA：广告展示 / 点击
  └── IAP：付费墙弹出 / 购买完成
```

## 二、功能模块拆解（按用户操作路径）

### 2.1 启动 → 首页

| 功能 | IAA 触发 | IAP 触发 |
|------|---------|---------|
| 开屏（Splash） | 开屏广告（3-5s），eCPM 最高 | 无（不打断首次体验） |
| 首页布局 | Banner 广告（底部/信息流） | 无 |
| 新手引导 | 无（不在这时展示广告） | 引导末尾：Pro 功能一览（可跳过） |

### 2.2 核心工具操作

| 功能 | IAA 触发 | IAP 触发 |
|------|---------|---------|
| 扫描/识别/计算（使用中） | 无（打断操作是大忌） | 无 |
| 处理完成/结果展示 | 结果页底部 Banner | 结果对比暗示（原图 vs Pro 增强） |
| 重复操作（第 N 次） | 插屏广告（任务完成间隙） | 用量限制触发 → 付费入口 |
| 高级功能点击（灰显🔒） | 无 | 预览效果 → 引导试用/付费 |

### 2.3 编辑 / 高级处理

| 功能 | IAA 触发 | IAP 触发 |
|------|---------|---------|
| 基础编辑（裁剪/旋转） | 编辑页底部 Banner | 工具栏中 Pro 功能灰显🔒 |
| 高级编辑（增强/滤镜/OCR） | 无（付费功能不插广告） | 🔒 点击 → 预览 → 付费墙 |
| 批量处理 | 无 | 🔒 点击 → 付费墙 |

### 2.4 导出 / 保存

这是**变现最密集的环节**——用户已完成任务，动机最强。

| 功能 | IAA 触发 | IAP 触发 |
|------|---------|---------|
| 格式选择 | Banner 广告 | 高清/无水印格式标记 Pro |
| 导出确认 | 插屏广告（导出完成后） | 水印对比 → 去水印 Pro |
| 保存到相册/本地 | 无 | 无 |
| 保存到云端 | 无 | 🔒 Pro 功能 |

### 2.5 分享

| 功能 | IAA 触发 | IAP 触发 |
|------|---------|---------|
| 分享文件 | 分享出去的 PDF 带水印（获客） | 无水印分享 → Pro |
| 分享页面 | Banner 广告 | 无 |

### 2.6 设置 / 个人中心

| 功能 | IAA 触发 | IAP 触发 |
|------|---------|---------|
| 设置页 | Banner 广告 | "升级 Pro"入口 |
| 个人中心 | 信息流广告（如积分墙入口） | 订阅管理 / 恢复购买 |

## 三、变现触发时机总览

```
用户路径：启动 → 操作 → 完成 → 导出 → 分享

广告触点：
  开屏(启动时) → Banner(使用中·底部) → 插屏(任务完成后) → Banner(结果页)

付费触点：
  引导(Pro一览) → 灰显(操作中·工具栏) → 限制(第N次触发) → 导出(格式/水印)
```

**广告和付费在同一路径上不互斥，但需要错开节奏：**
- 使用中：不打断（无广告、无付费弹窗）
- 任务完成后：先展示结果价值 → 再触发变现（广告或付费入口）
- 导出时：这是两者并存的高频场景——Banner 做广告，格式选择做付费引导

## 五、功能设计自检

- [ ] 核心操作路径上，哪些环节插广告、哪些环节引导付费？是否错开？
- [ ] 任务**进行中**是否保持了零打扰（无广告 + 无弹窗）？
- [ ] 任务**完成后**是否有变现触点（Banner / 插屏 / 对比暗示 / 升级入口）？
- [ ] 灰显功能是否在主操作路径上可见（不在三级菜单）？
- [ ] 导出环节是否同时承载了广告（IAA）和付费引导（IAP）？
- [ ] 付费版去广告后，免费版的广告频次是否在用户容忍范围内？
- [ ] 分享出去的成果是否带水印（既是获客也是付费动机）？
