# AMDC 当前进度

最后更新：2026-07-28

## 已完成

- 采集流程固定为两阶段：先确认全部周榜单，再按日期从新到旧逐周采集应用国别；每周使用完整账号池
- 总进度按所有采集周的“已解决国别应用数 / 重点应用总数”汇总，切换查看周不会重置进度
- 区分“周任务完成”和“总任务完成”；只有所有周完成后才触发总任务完成
- 运行或同步期间禁止刷新看板；取消重采会恢复之前的历史记录
- 进度文件改为原子写入，并保留短暂初始化时最后一次有效国别进度，降低进度回退闪烁
- 单周失败只补采缺失国别数据，不重跑已完成应用；429 和网络错误走冷却或重试

## 本次规则（1.1.3）

- 某重点应用连续三次得到“接口成功，但没有有效国别数据”的结果，写入 `countryStatus: "默认下架"` 并放行
- “默认下架”计入国别已解决数，因此不会阻塞该周和整批完成
- 网络错误、请求异常和 HTTP 429 不增加这三次计数，避免误判
- 计数保存到富化缓存：`countryMissingAttempts`，跨“只补采缺失国别数据”的重试继续累计
