# AppMagic市场分析约束

## 私有资源配置

- 固定资源地址不写入Skill、引用文件、日志、报告正文、提交或远程仓库；每次运行先执行配置校验脚本，由脚本从本机应用数据私有目录读取配置，或读取环境变量`AM_MARKET_ANALYTICS_CONFIG`指定的配置文件。
- 配置必须提供`data_workbook.url`和`formal_document.url`。`data_workbook.url`用于读取唯一数据工作簿和生成“AppMagic数据”的原生表格链接对象；`formal_document.url`用于读取确认后的正式覆盖目标。
- 配置文件缺失、字段缺失或地址无效时停止流程；不得搜索云文档、向用户索要已固定资源或自行猜测地址。
- 每次调用前执行`scripts/verify-local-resource-config.ps1`。该脚本只输出校验状态，不输出资源地址。
- 账号标识、访问令牌、机器绝对路径和本地配置内容同样不得进入Skill、报告、日志、提交或远程仓库。

## 数据边界

- 只使用本地配置中`data_workbook.url`绑定的固定AppMagic工作簿，读取其中全部日期命名且可见的周度工作表；不得搜索云文档或扩展资料范围。
- 文档首段固定写为“基于AppMagic数据的全量历史周度数据整理，供审校确认。确认前不会覆盖正式市场分析文档。”其中“AppMagic数据”必须保留为指向`data_workbook.url`的原生表格链接对象，不得改成纯文本、普通超链接或其他文档链接。
- 计算单位是“应用×周”记录中的Top5国家份额；同一记录内先归一化，再跨记录聚合。
- 下载国缺失不参与下载计算；收入国缺失不视作零收入。
- 下载国Top5识别IAA用户规模与潜在广告库存偏好；收入国Top5识别IAP收入偏好。

## 判断、图表与验收

- 下载侧判断IAA规模层，收入侧判断IAP优先级；US可单独分析，其他国家优先写群组角色。
- 覆盖率低时只提出候选群组或小规模测试；休闲、超休闲和工具品类分别判断。
- 以下为当前已确认的四张图表基准，后续更新只替换数据、日期和必要的说明文字，不重新设计图表结构、间距、对齐方式或视觉样式。
- 图表必须由`templates/`中的批准版SVG模板和`references/chart-layout-contract.json`中的版式参数生成；使用`scripts/render-market-charts.ps1`读取结构化JSON数据。模型不得直接生成新的SVG布局或修改模板坐标。
- 当前批准版统一使用1600×980白色画布，根SVG固定为1640×1020和`viewBox="-20 -20 1640 1020"`；确因新增周期或行数会裁切时，只允许沿Y轴增加高度，禁止增加画布、绘图区、根SVG宽度或任何横向坐标。统一内容框上锚点距白色上边界36px、下锚点距白色下边界48px；普通内容不得超出白色边界，折线图绘图区左右边距必须严格相同。
- 图表大标题固定使用56px；“下载侧”“收入侧”“品类”“收入覆盖率”等黑色分区标题固定使用36px；副标题、图例、注释、口径说明、坐标轴、刻度、普通分类标签和数据标签固定使用24px；所有可见文字不得低于24px。
- 四张图的标题、简介和首条上分隔线绝对左边界统一固定为白色画布`x=50px`；标题下沿固定为绝对`Y=82.589px`，简介视觉中心固定为`Y=148.589px`，首条上分隔线固定为`Y=214.589px`，三者按`66px`等差距离定位；不得因单次更新改变标题区、图例区、数据区和口径说明的纵向节奏。
- 首条上分隔线到首个图例/内容锚点的垂直间距固定为49px；P1、P2、P3、P4必须使用同一数值，首内容锚点仅允许移动图例/首内容组本身，不得因此整体上移P4已有地区行或改变下边界、注释位置。
- 柱内数字固定使用24px常规字重，不得加粗；柱内文字和文字框均以对应柱段实际矩形中心为准，上下、左右居中。图例整体居中且相邻图例项间距不得小于24px；空间足够时标签保持单行；纵坐标刻度统一右对齐。
- 全球主分组结构图不得显示“100%堆叠”文字；柱上、柱下“下载侧”“收入侧”必须以对应柱体水平中心为准，且柱顶至上方标题的距离等于柱底至下方标题的距离。
