# 自适应证据门槛

## 核心原则

不用统一 DAU 门槛判断数据是否可分析。按指标实际分母、历史波动、观察窗口、维度粒度和业务影响决定结论强度。DAU 只用于描述项目规模和选择观察周期。

同一项目可以同时出现不同置信度：DAU 趋势可信，某个小广告源的竞胜率仍可能不可判断；日活只有几十，但每天产生数千次广告请求时，请求填充率也可能有足够证据。

## 分析前置条件

以下任一条件不满足时，停止统计判断并先处理数据问题：

1. 日期、时区、币种和数据来源明确。
2. 对比周期的字段口径与维度粒度一致。
3. 比率能取得分子、分母，或明确标记为平台直接返回且不可复算。
4. 缺失、接口未返回和真实零值能够区分。
5. 汇总行、明细行和非可加指标没有重复聚合。

## 自动选择观察窗口

从完整自然日的 7 天对 7 天开始，保持星期结构一致。证据不足时依次扩展为 14、28、56 天；达到可用等级后停止扩展。

- 日活和事件量稳定：优先 7 天或 14 天。
- 日活几十到几百且波动大：优先 28 天或 56 天，并以周为最小展示单位。
- 新用户、留存和 LTV：按 cohort 成熟度选择窗口，不把尚未成熟的 D7、D30、D60 当作完整数据。
- 版本发布、节假日或投放变化导致周期不可比：不用扩大窗口掩盖结构变化，改做事件前后分段。

若 56 天仍不足，将结论降为“描述性观察”，不继续通过扩大窗口制造稳定表象。

## 按指标计算不确定性

### 计数指标

对展示、点击、请求、填充和竞价次数使用实际事件数评估误差。事件稀少或过度离散时，使用 bootstrap 或负二项分布，不只依赖泊松假设。

### 比率指标

对填充率、展示率、CTR、竞价响应率、竞胜率、Ready 率和留存率使用原始分子、分母计算 Wilson 或 Beta 区间。不能只根据 DAU 或平台返回的百分比判断稳定性。

### 收益、eCPM 和 ARPDAU

收益比较同时报告绝对差额、相对变化和对总差额的贡献。eCPM、ARPDAU 等比值指标从原始分子、分母重算，并使用按天的 block bootstrap 或 delta method 估计变化区间。不要平均行级比值。

### 维度拆分

按国家、广告位、广告源、版本或流量分组拆分时，重新评估每个切片的分母和区间。切片不足时向上合并到广告位、广告平台或应用层，并把长尾归入 `Other`。总体可信不代表每个切片可信。

## 变化判定

同时满足统计证据和业务影响才称为“确认变化”：

```text
practical_threshold = max(用户指定的最小业务影响, 历史同口径噪声上界)
```

没有用户指定值时，用最近可比历史周期的变化分布估计噪声上界；历史不足时只报告变化区间，不自动给出配置动作。

| 等级 | 判定 | 允许输出 |
|---|---|---|
| A 可决策 | 数据质量通过；95% 变化区间不跨 0；超过 practical_threshold；主要替代解释已检查 | 明确诊断，可提出小流量实验和量化决策条件 |
| B 可行动验证 | 数据质量通过；方向在多个窗口或主要切片中一致，但区间较宽、业务影响接近门槛或仍有重要替代解释 | 标记方向性证据，只建议验证实验 |
| C 仅观察 | 区间宽、方向不稳定、分母不足、窗口短或关键维度缺失 | 描述现象、合并维度、延长窗口或列补数项 |
| D 不可用 | 口径冲突、缺页、重复聚合、分子分母错误或周期不可比 | 不做业务结论，先修复数据 |

不要把统计显著等同于收益重要，也不要把绝对变化大等同于原因已经确定。

## 异常检测

使用同星期结构的历史数据建立基线。优先采用滚动中位数、MAD、分位数带和季节性残差，减少小项目极端值对均值和标准差的影响。

- 单日越界：标记异常候选，不直接归因或改配置。
- 连续两期同向，或对总收益差额贡献集中：提升调查优先级。
- 多维度同时扫描：控制多重比较，使用 FDR 或只报告预先登记的核心切片。
- 新项目历史不足：使用宽区间和 C 级输出，随数据积累自动收紧。

## 实验门槛

实验前根据基线方差、目标最小变化和实际流量估算样本量。低流量项目优先延长实验并减少实验组数，不降低成功标准。

只有满足以下条件才允许扩大配置：

1. 主要指标达到预先登记的最小业务影响。
2. 区间支持预期方向，且结果不是单日或单一异常切片驱动。
3. 收入、留存、稳定性等护栏未恶化。
4. 分组比例、版本、地区和广告位结构可比。

## 输出要求

每个主要结论附上：观察窗口、粒度、实际分母、变化区间、practical threshold、证据等级和降级原因。若只能取得日级汇总数据，明确说明区间方法和无法验证的假设。
