# 全自动加载

## 关于全自动加载

全自动加载模式，是TopOn推出的一站式请求维护方案，能够根据用户的使用状态和广告消耗进度，多节点智能判断下一条广告的预加载和缓存时机。在满足您运营策略的基础上，规避广告数据实时加载的失败风险和展示机会被浪费，减轻用户因为广告未加载或加载不流畅造成的负面情绪。通过全自动加载方案，您可以避免反复冗杂的人工干预请求方案，效率提升立竿见影！

支持的广告形式有：[**激励视频广告**](/cn/docs/quan-zi-dong-jia-zai-ji-li-shi-pin-guang-gao)和[**插屏广告**](/cn/docs/quan-zi-dong-jia-zai-cha-ping-guang-gao)。
