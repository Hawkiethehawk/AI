# 监控预警

## 1. 功能概述

您可通过设置监控预警规则，选择对应用、广告类型、广告位等不同维度的各个数据指标，包括收益、展示、eCPM等进行数据波动监控，我们将会通过站内信和邮件形式每日定时反馈数据给您，协助您及时发现数据问题。

## 2. 操作指引

### 2.1 添加监控预警

您需要先添加监控规则，选择需要监控数据波动的维度和指标。

**(1) 进入监控预警功能**



**(2) 添加规则**



根据不同的场景选择不同的监控类型：

- **非AB测试**：支持选择不同的维度，指定应用、广告位等，针对对应维度的特定指标进行监控。
- **AB测试**：若您正在进行AB测试，支持将针对正在生效的AB测试实验，监控具体指标的对比效果波动（**默认会选择AB测试ID最大和最小的分组进行数据对比**）。需要在页面勾选应用或者勾选对应的AB测试进行监控。

**(3) 相关数据说明**

点击添加规则时按照您需要监控的维度和指标进行设置，具体的指标说明请查看下表：

| 指标名称 | 可选项 | 指标含义 | 说明及建议 |
| --- | --- | --- | --- |
| 监控类型 | 非AB测试/AB测试 | 区分监控的内容，非AB测试为常规数据监控；AB测试为监控AB测试对比结果的数据波动 | 若您没有在使用AB测试，仅需要关注日常的数据波动，请选择【非AB测试】类型 |
| 监控维度 | 账号、应用、广告位、广告源、广告平台、广告类型 | 根据选择的维度进行数据指标数据汇总例如：选择账号维度的预估收益指标，则统计账号总预估收益 | 可通过不同维度监控不同的指标内容，一个规则只支持单个维度 |
| 数据时间 | 不可选择，只支持对最近一天的数据监控 | 后台数据延迟一天展示，1月2日的最近一天为1月1日，即1月2日会收到1月1日异常数据的预警消息 |  |
| 触发条件 | 满足以下任一条件、满足以下所有条件 | 设置多个条件时，可设置是否需要同时满足设置的指标 | 若需要设置同时监控数据上涨和下跌，则需要设置满足上涨或下跌任一条件，可查看下列示例 |
| 触发条件-监控指标 | DAU、DEU、预估收益、人均收益、eCPM、展示/DAU、展示/DEU、渗透率、流量请求等 | 对应指标含义可查看：[综合报表指标说明](/cn/docs/DVM3Tf#5.2_%E6%95%B0%E6%8D%AE%E6%8C%87%E6%A0%87) | 提供的指标与报表的指标含义一致，可通过综合报表对应的数据情况确定设置的阈值 |
| 触发条件-对比类型 | 上周同期、前天、特定值 | 对比最近一天与更早的数据或特定的值 - 上周同期：数据时间的上周同一天 - 前天：数据时间的前一天 - 特定值：设置特定的值监控（可用于eCPM、展示率、Gap） |  |
| 触发条件-数值类型 | 数值、百分比 | 支持按照数值或百分比计算指标 |  |
| 监控周期 | 不同时区、半个小时为维度选择 | 到达设置的监控周期时间点时，会对监控指标进行计算和对比，满足触发条件则会在计算后发送对应通知 | 设置时间为计算数据时间，而非发送通知时间 |
| 通知方式 | 站内通知、邮件 | 可选择对应的通知方式接收监控预警内容 | 添加多个邮箱可用英文逗号隔开 |

需要查看账号下各个应用的收益波动，可设置监控应用维度，预估收益指标比前一天上涨或下跌20%，具体配置如下。



**(5) 各指标监控周期时间设置**

① TopOn统计数据（无API后缀数据）：我们统计的数据将在北京时间每日9：00前完成统计，针对此类数据的监控时间可设置为9点及以后

② API数据：各个平台的API数据更新时间不一致，可点击【监控时间点建议】查看



添加规则后，在设定的监控周期中，我们会根据设置的规则每天定时计算，数据触发告警后，您将收到站内通知或邮件通知，可在监控预警中查看命中规则的详细内容。

### 2.2 查看监控预警

收到预警通知后，您可点击通知查看当日的所有触发告警的数据异常提醒，及时发现各维度出现的数据问题。

**(1) 站内通知、邮件通知**

选择通知方式之后，会在站内通知/邮件查看到对应的监控指标数据情况，点击可跳转监控预警中心查看对应的内容。



**(2) 后台查看监控预警内容**

在监控预警中可查看每条规则的命中数量，点击【详情】可查看对应维度命中规则的监控指标具体数据。





目前暂不支持查看查看异常报表数据，您可通过综合报表查看对应的数据情况。

**注意：**

**针对AB测试类型的监控，最近一天的数据可在AB测试页面，广告位数据汇总报表查看对应指标的【对比结果】数据。**

## 3. 常见问题

**(1) 设置了新规则什么时候会开始通知?**

设置的规则预警时间在当前时间之后，当日的预警立即生效，否则会次日开始生效。示例：2022/1/1 9:00 设置了每日10:00预警，则2022/1/1 10:00就会收到首次预警通知；2022/1/1 10:00 设置了每日9:00预警，则次日，即2022/1/2 9:00才会收到首次预警通知。

**(2) 设置了邮件通知但收不到邮件?**

可先查看垃圾箱是否有邮件，因太频繁发送邮件可能会导致此问题。如无任何通知，请联系运营同事。

**(3) 监控API的数据时，有时候没有预警如何排查?**

监控的API数据因为各个平台更新时间不一致，无数据时会导致预警无法正常使用，请根据后台提示的【监控时间点建议】合理设置监控时间。
