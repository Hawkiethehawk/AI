# 交叉推广报表

## 1. 功能概述

通过交叉推广功能，可实现不同产品之间的互相推荐导流。交叉推广报表，用于查看使用交叉推广功能后的相关方面数据表现。

**如何使用交叉推广报表？**

开发者如需开通交叉推广报表功能，请先向TopOn申请相关权限，并按照[**交叉推广说明文档**](/cn/docs/Popzgt)进行配置。



## 2. 相关数据说明

### 2.1 数据筛选项

| 筛选项 | 说明 |
| --- | --- |
| 日期 | 数据产生的时间段。**注意**：每次最多选择60天的日期。 |
| 产品 | 待通过使用交叉推广功能投放获量的产品。[>>如何添加产品？](/cn/docs/Popzgt#3.2_%E6%B7%BB%E5%8A%A0%E4%BA%A7%E5%93%81) |
| 广告 | 待通过使用交叉推广功能投放获量的产品的广告创意。[>>如何添加广告？](/cn/docs/Popzgt#3.3_%E6%B7%BB%E5%8A%A0%E5%B9%BF%E5%91%8A) |
| 地区 | 用户所在的国家/地区 |
| 应用 | 在TopOn创建的应用。 [>>更多](/cn/docs/pzi00q) |
| 广告位 | 在TopOn创建的广告位。 [>>更多](/cn/docs/pzi00q#2._%E5%B9%BF%E5%91%8A%E4%BD%8D%E7%AE%A1%E7%90%86) |
| 广告样式 | 在TopOn创建的广告位对应的广告样式：激励视频、插屏、原生、开屏、Banner |
| 流量分组 | TopOn提供多个维度对用户进行分组，不同的流量分组可以配置不同的Waterfall，以实现精细化流量变现。目前TopOn支持的流量分组维度具体如下： 地区，广告样式，应用，广告位，日期，小时，网络类型，应用版本，SDK版本，设备类型，设备品牌，安装时间，渠道，子渠道和自定义规则。 [>>更多](/cn/docs/KjVUSq) |
| 广告场景 | 广告场景是在一个广告位下创建多个广告场景，可以有效的区分不同广告场景下的展示、点击数据。适用于应用内有多个广告场景同时需要区分展示数据的产品。[>>更多](/cn/docs/pzi00q#3._%E5%B9%BF%E5%91%8A%E5%9C%BA%E6%99%AF) |

### 2.2 数据指标

分小时报表支持的数据指标。



| 数据指标 | 说明 |
| --- | --- |
| 日期 | 数据产生的时间段 |
| 收益 | 交叉推广的预期收益，根据TopOn SDK统计的展示数和广告eCPM价格进行预估的收益。 计算公式：人工填写的广告eCPM价格\*TopOn统计的展示/1000 |
| 请求 | 即广告源请求。TopOn按照聚合管理的瀑布流广告源排序向交叉推广广告源发起的请求次数 |
| 填充率 | 即广告源填充率。TopOn按照聚合管理的瀑布流广告源排序向交叉推广广告源发起请求后，广告返回成功的占比。计算公式：广告源请求返回成功数（广告源填充数）/请求\*100% |
| 展示 | TopOn统计的广告曝光次数 |
| eCPM | eCPM（effective cost per mile）指的是每一千次展示可以获得的广告收入。计算公式：（交叉推广的预估收益/展示）\*1000 |
| 点击 | TopOn统计的广告点击数。 |
| 点击率 | TopOn统计的广告点击数占TopOn统计的广告曝光次数的比例。计算公式：点击/展示\*100% |
