# TopOn账号管理

## 1. TopOn账户注册常见问题

**(1) 注册TopOn账号** 请打开[TopOn官网](https://portal.toponad.net/m/register)注册账号，按要求如实填写信息即可。

**(2) 支持个体开发者注册** TopOn支持个人开发者及个体工商户注册。

**(3) 报表币种** 报表币种为您后续在TopOn后台查看数据的币种（支持人民币或美元），无法随意切换，请按需选择。

**(4) 技术&运营对接支持** 账号注册后会有TopOn商务经理与您联系，届时会根据需要安排技术运营对接群，请开放您联系方式的好友添加权限。

**(5) 与我们联系** 有任何问题，也欢迎发送邮件至TopOn支持团队。

联系邮箱：[support@toponad.net](mailto:support@toponad.com)



## 2. 如何修改注册邮箱

不支持开发者直接在TopOn后台更改注册邮箱，如有需要，请联系TopOn商务运营团队。



## 3. 如何修改密码

如需修改账号密码，请登录后在“账号管理”页面自行修改。

**路径：TopOn后台→【账号管理】-【账号信息】-【修改密码】**



## 4. 如何添加和管理子账户

TopOn支持子账号功能，不同角色账户拥有不同的功能操作与数据查看权限。

**路径：TopOn后台→【账号管理】-【子账号设置】→【+子账号】**

- **应用范围：**支持授权指定应用权限。
- **权限：**支持授权【运营】和【报表】两种权限。 运营权限允许角色调整指定应用的运营策略和后台配置； 报表权限允许角色查看指定应用的数据报表，无法调整后台配置。
- **查看页面：**运营权限下，支持设置查看页面为仅查看应用和聚合管理。



## 5. 如何修改账户的币种

不支持开发者直接在TopOn后台更改账户币种，如有需要，请联系TopOn商务运营团队。



## 6. 如何与TopOn进行结算

TopOn是免费的聚合管理工具，支持直接注册使用，三方广告平台使用您自己的账号，无需与TopOn进行结算。

注：若使用[**TopOn ADX**](/cn/docs/0a2ZxO)功能，在开始结算之前，请您务必先联系TopOn商务运营团队签署合作协议。如果您还没有对接人，可以发送邮件至[bdam@toponad.net](mailto:bdam@toponad.net)沟通合同签署事宜。

完成后，请在TopOn后台开启以下流程：

(1)填写财务信息 >> (2)确认结算金额 >> (3)上传发票信息 >> (4)发票审核 >> (5)支付打款
