# 直投广告

## 1. 功能概述

通过直投广告功能可实现投放直客广告。

目前TopOn支持多种的广告样式，包括：**激励视频、插屏视频、插屏图片、原生、开屏、Banner**。

我们建议您根据自身需求选择不同的功能来投放广告：

| 功能 | 推荐使用场景 |
| --- | --- |
| 交叉推广 | 推广自有应用，且不需要精准的展示预算控制。一般在三方广告平台无填充时用交叉推广兜底 |
| 直投广告 | 推广直客广告，且需要对广告进行展示预算控制 |

## 2. 操作指引

### 2.1 开通直投广告权限

(1) 联系TopOn开启**直投广告**权限(目前只对白名单用户开放)。

(2) 使用直投广告需要更新**TopOn SDK >= v5.7.92。**

### 2.2 配置直投广告

直投广告的广告层级规则如下：**广告组 > 广告计划 > 创意。**

- **广告组**：对应一个**Android应用、iOS应用、网页应用。**
- **广告计划**：一个广告组下可以创建多个广告计划。每个广告计划可以在多个TopOn广告位下投放。
- **创意**：每个广告计划可以创建一套创意。



### 2.3 查看直投广告报表

您可以在**数据报表 > 直投广告报表**查看明细的直投广告数据。





## 3. 详细步骤及说明

### 3.1 配置广告组

(1) 在 **高级设置 > 直投广告** 进入配置页面

(2) 可以在广告组中创建和管理广告组

(3) 添加广告组时，广告组类型支持：**Android App、iOS App、网页**

(4) 当添加的**广告组类型=Android，且不在Google Play上架**，同时如果您的产品组是在中国大陆地区推广，建议您加上工信部要求的APK广告的四要素

**① 应用版本**：您应用的版本号

**② 应用权限URL**：您应用需要申请的权限说明文档链接地址

**③ 隐私协议URL**：您应用的隐私协议文档链接地址

**④ 开发者名称**：您的名称

### 3.2 配置广告计划

(1) 您可以在**广告计划**中创建和管理广告计划

(2) 在创建广告计划时您需要完成以下步骤：

#### **① 选广告组**

您需要选择广告组来源，目前支持：**已有广告组、创建新广告组**



#### **② 广告计划-基本信息**

在**广告计划-基本信息**中完成以下内容的配置



各项配置说明如下：

| 选项 | 是否必填 | 说明 | 备注 |
| --- | --- | --- | --- |
| 开始日期 | 必填 | 广告计划的开始日期 | 可选择开始日期的时区 |
| 结束日期 | 必填 | 广告计划的结束日期 | 广告计划到达结束日期后会自动结束 |
| eCPM结算价格 | 必填 | 报表中的收益数据将采用eCPM结算价格进行计算 | eCPM结算价格的币种跟账号币种一致 |
| 总展示数 | 可选 | 广告计划的总展示数，支持按天、推广周期设置 | 广告计划正在投放时，如果减少总展示数可能会导致展示预算控制不准，请谨慎修改。 |
| 总点击数 | 可选 | 广告计划的总点击数，支持按天、推广周期设置 | 广告计划正在投放时，如果减少总点击数可能会导致点击预算控制不准，请谨慎修改。 |
| 单设备展示数 | 可选 | 单台设备上的展示数，支持按推广周期设置 | 广告计划正在投放时，如果减少单设备展示数可能会导致预算控制不准，请谨慎修改。 |
| 单设备点击数 | 可选 | 单台设备上的点击数，支持按推广周期设置 | 广告计划正在投放时，如果减少单设备点击数可能会导致预算控制不准，请谨慎修改。 |

#### **③ 广告计划-第三方检测链接**

在**广告计划 - 第三方检测链接**中完成以下内容的配置



各项配置说明如下：

| 选项 | 是否必填 | 说明 | 备注 |
| --- | --- | --- | --- |
| 点击跳转地址 | 必填 | 直投广告的点击跳转链接 | 支持占位符替换。[点击跳转地址配置说明](/cn/docs/1oU8Bm) |
| 点击上报地址 | 可选 | 直投广告的点击监测链接 | 支持占位符替换 |
| 展示上报地址 | 可选 | 直投广告的展示监测链接 | 支持占位符替换 |
| Deeplink地址 | 可选 | 跳转到已安装App的指定页面 | 支持占位符替换 |
| 跳转方式 | 必填 | 跳转方式支持: **应用市场**：通过Google Play 或 App Stores打开 **浏览器打开**：通过浏览器打开 **内置浏览器(WebView)**：通过内置WebView打开 **APK下载**：下载APK广告 | APK下载仅针对TopOn Android国内版本有效 |

#### **④ 广告计划-用户定向**

在**广告计划 - 用户定向**中完成以下内容的配置



各项配置说明如下：

| 选项 | 是否必填 | 说明 | 示例 |
| --- | --- | --- | --- |
| 指定时间段 | 可选 | 按星期及小时选择直投广告投放时间范围 | - |
| 投放地区 | 必填 | 投放地区区分中国大陆和非中国大陆。**如果需要全球投入请添加两个不同投放地区的直投广告** | - |
| 网络类型 | 可选 | 可以指定WiFi、4G、3G、2G | - |
| 应用版本 | 可选 | 可以指定应用版本 | 2.10.11 |
| SDK版本 | 可选 | 可以指定TopOn SDK版本 | 5.7.92 |
| 系统版本 | 可选 | 可以指定系统版本 | 14.5.0 |

### 3.3 在TopOn广告位上投放广告计划

(1) 您需要在**聚合管理**中为投放直投广告的TopOn广告位**添加直投广告源**



(2) eCPM结算价格及排序价格说明：添加广告计划时设置的eCPM结算价格与聚合管理设置的排序价格相互独立

| 价格类型 | 说明 |
| --- | --- |
| eCPM结算价格 | 在**广告计划**里配置，报表数据的**收益**会根据eCPM结算价格计算，常用于跟直投广告主结算 |
| 排序价格 | 在**广告源**里配置，用于确定直投广告源在WaterFall中的排序 |

### 3.4 高级功能

**(1) 设置过滤投放包名**

可以针对直投广告设置排除包名的列表，被排除的包名所对应的产品不会再被推广

**Android**

| API | 参数 | 说明 |
| --- | --- | --- |
| setExcludePackageList | (List packageList) | **packageList**：被排除的应用包名列表 |

**iOS**

示例代码：

```
    [[ATAPI sharedInstance] setExludeAppleIdArray:@[@"id529479190"]];
```
