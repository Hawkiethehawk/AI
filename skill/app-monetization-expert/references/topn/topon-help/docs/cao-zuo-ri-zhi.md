# 操作日志

为有效防控因多角色登录引发的操作风险，TopOn平台全新上线了操作日志功能模块。在此功能下，管理员能够在专门的操作日志页面精准查阅团队成员过往的操作记录详情，实现每一项操作步骤的全程可追溯。

## 1. 功能入口及权限说明



功能入口：后台→【账号管理】→【操作日志】

权限：目前功能还在灰度上线中，如有需要请联系AM开通；当前版本仅支持主账号查看操作日志，子账号的操作日志功能暂未上线。

## 2. 操作日志支持内容

当前版本操作日志针对开发者高频的操作进行记录，主要包括以下内容

| **操作类型** | **支持操作内容** |
| --- | --- |
| 广告位 | 1.新增/编辑广告位  2.新增/编辑广告场景  3.复制广告位 |
| 聚合管理 | 1.新增/编辑广告源  2.高级设置编辑  3.新增/编辑流量分组 |
| A/B测试 | 1.新增/编辑A/B测试 |
| 智能管家 | 1.开启/关闭智能管家 |

##

## 3. 快速搜索操作日志

为了快速定位具体操作日志，您可通过操作类型、操作对象、操作对象信息、动作进行检索

(1) 操作类型：包括广告位、聚合管理、A/B测试、智能管家

(2) 操作对象：操作最细粒度的对象，支持输入广告位/ID、流量分组/ID、广告源/ID、A/B测试分组名称/ID等对象信息

(3) 操作对象信息：操作对象的从属信息，支持输入应用/ID、广告位/ID、流量分组/ID、A/B测试分组名称/ID等对象信息，可通过操作对象信息查询需要具体某个应用/广告位的操作日志

(4) 动作：新增、删除、编辑，可通过动作进行快速查询

(5) 操作人：进行操作的账号名称，可查看具体某个账号发生的操作
