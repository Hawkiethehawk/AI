# Google数据安全指南

[根据Google数据安全](https://support.google.com/googleplay/android-developer/answer/10787469?hl=zh-Hans)要求，您需要披露App和集成在App中所有SDK收集的数据。

下文列出了TopOn SDK收集的数据，可用于回答Google的数据安全调查问卷。

> 注意：
>
> 1. 此信息仅用于回答Google的数据安全调查问卷，具体TopOn隐私合规指南请阅读 [《TopOn隐私合规指南》](https://help.toponad.net/cn/docs/ByIf1V)。
> 2. 下面介绍TopOn SDK自动收集的数据，但不包括由任何第三方广告平台SDK收集的数据。

## 1. 数据收集和安全

| SDK是否收集或共享任何所需的用户数据类型？ | SDK收集的所有数据在传输过程中是否都经过加密？ | SDK是否提供用户请求删除其数据的方法？ |
| --- | --- | --- |
| 是 | 是 | 是 |

---

## 2. 数据类型

| 数据类型 | 使用范围 | 是否收集 | 是否共享 | 收集和共享的目的 |
| --- | --- | --- | --- | --- |
| 位置 | 不适用 | 否 | 否 | 不适用 |
| 个人信息 | 不适用 | 否 | 否 | 不适用 |
| 财务信息 | 不适用 | 否 | 否 | 不适用 |
| 健康信息 | 不适用 | 否 | 否 | 不适用 |
| 信息 | 不适用 | 否 | 否 | 不适用 |
| 照片或视频 | 不适用 | 否 | 否 | 不适用 |
| 声音文件 | 不适用 | 否 | 否 | 不适用 |
| 文件和文档 | 不适用 | 否 | 否 | 不适用 |
| 日历 | 不适用 | 否 | 否 | 不适用 |
| 交往 | 不适用 | 否 | 否 | 不适用 |
| 应用活动 | 默认使用 | 是-应用互动;其他动作（与广告互动） | 是-应用互动;其他动作（与广告互动） | 应用互动：分析；其他动作：分析、欺诈预防、安全性和合规性； 广告或营销。 |
| 网页浏览 | 不适用 | 否 | 否 | 不适用 |
| 应用信息及性能 | 不适用 | 否 | 否 | 不适用 |
| 设备ID及其他ID | 选择性使用 | 是 | 是 | 分析、欺诈预防、安全性和合规性； 广告或营销。 |
