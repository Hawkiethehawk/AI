# 交叉推广

## **1. 功能概述**

交叉推广(cross-promotion) 是一种市场推广策略，指向某一款产品的用户推荐与之相关的另一款产品。通过交叉推广功能，可实现不同产品之间的互相推荐导流。 目前TopOn支持交叉推广多种的广告样式，包括：**激励视频、插屏视频、插屏图片、原生、开屏、Banner**。



## 2. 使用场景

- 自有产品导量：如可通过交叉推广功能在应用A中投放应用B的广告。
- 投放直客广告主广告：如有一些直客的单子，可以直接通过交叉推广功能投放。
- 广告填充率较低时作为兜底：当集成的广告平台资源不足或者用户网络较差时，可以开启交叉推广功能进行填充率的补充。因为交叉推广的广告一旦缓存到本地，可以不需要重复下载广告资源直接展示。

## 3. 操作指引

### 3.1 如何设置交叉推广

(1) 使用交叉推广功能之前需**联系TopOn开启对应权限**(默认不开放)。

(2) 开通“交叉推广”功能后，可在聚合管理页面控制交叉推广的开启与关闭。

(3) 可在每一个waterfall中控制该交叉推广广告的开关

(4) 可在聚合管理的高级设置页面批量控制对应广告位各waterfall的“交叉推广”广告。

### 3.2 添加产品

**(1) 输入产品名称**

**(2) 选择产品类型**

目前**产品类型**支持: **Android、IOS、网页**

① 当**产品类型=Android**时，需选择是否上架Google Play，并按对应要求输入产品链接及Package Name。

**注：**Packgame Name为必填项，如客户端已安装同包名产品，TopOn会自动拉起此产品，无需重复下载。



**② 当产品类型=iOS时**，需选择是否上架App Store,并按对应要求输入产品链接，App Store ID为选填项。



③ 当**产品类型=网页**时，填写网页链接即可



### 3.3 添加广告

**(1) 添加广告**

点击操作下方齿轮，点击【添加广告】



**(2) 填写基本信息**

填写基本信息包括：**广告名称、点击跳转地址、展示上报地址、Deeplink地址、跳转方式**

**① 广告名称：**自定义命名

**② 点击跳转地址/展示上报地址：**详情请参阅 [点击跳转地址配置说明](/cn/docs/1oU8Bm)

**③ Deeplink地址：**可跳转至已安装应用的指定页面，非必填。

**④ 跳转方式：**有以下三方方式，具体按照所推产品实际情况选择。

- **应用市场：**跳转Google Play\Apple Store
- **浏览器打开：**跳转至浏览器打开
- **APK下载：**主要用于国内产品推广(添加产品时，Google Play上架需要选择否）

**(3) 选择投放广告位**



- 选择投放广告位有两种方式：

**选择广告样式：**勾选广告样式后，账号下**已有及新增**对应样式所有广告位均会自动关联当前广告，在下列已选择广告位列表可查看具体关联广告位（新增的广告位将自动勾选）。

**选择特定广告位：不勾选任何广告样式**，可在已选择广告位列表勾选已有广告位关联。若有广告位新增且需要关联当前交叉推广广告，需要手动勾选对应的广告位。

**注意**：每个广告位每次请求广告时最多下发3个交叉推广广告; **如有特殊需求，请与我们联系**

**(4) 定向设置**



- 在此页面可针对具体的投放需求进行设置，包括开始和结束时间、投放时间段、投放区域、设备、展示预算、展示上限间隔等等。
- 价格如何填写？

开通交叉推广后，即在waterfall里开了一层广告源，交叉推广的价格需要按照实际情况填写，价格值将与聚合管理页面其他广告源价格一起对比进而排序。

**举例说明：**在以下waterfall里，如果交叉推广广告源的价格设置为11，那么交叉推广广告源排在第一顺位；如价格设置为3，则排在最后顺位。

**(5) 素材管理**

请按照要求完成素材配置，需重点注意的是：**视频格式仅支持mp4文件**

更多详情请查阅： [交叉推广广告素材管理说明](/cn/docs/8tczxn)

### 3.4 高级功能

**(1) 设置过滤投放包名**

可以针对交叉推广设置排除包名的列表，被排除的包名所对应的产品不会再被推广

**Android**

| API | 参数 | 说明 |
| --- | --- | --- |
| setExcludePackageList | (List packageList) | **packageList**：被排除的应用包名列表 |

**iOS**

示例代码：

```
    [[ATAPI sharedInstance] setExludeAppleIdArray:@[@"id529479190"]];
```

## 4. 注意事项

- **视频格式仅支持mp4文件（.mp4）。其他广告样式的素材要求请查看：交叉推广广告素材要求**
