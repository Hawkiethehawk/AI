# 分析报告输出规范

## 固定结构

1. 分析对象：应用、平台、广告位、国家和时间范围。
2. 数据口径：来源、币种、时区、粒度、预估或结算。
3. 主要发现：只写能由观测和计算支持的变化。
4. 贡献拆解：展示量、eCPM、漏斗和主要维度。
5. 原因假设：按证据强弱排序，并列出替代解释。
6. 建议与实验：对象、范围、指标、护栏和回滚条件。
7. 数据限制：缺失字段、不完整周期、重复粒度和口径冲突。
8. 参考资料：使用过的 TopOn 官方页面 URL。

## 写法

先给结论，再给证据。每个核心句子使用 `[观测]`、`[计算]`、`[推断]` 或 `[建议]`。避免“明显”“一定”“最佳”等超出证据的词。

报告中的百分比同时给分子和分母，或给当前值与基线值。相对变化可能在小基数上失真，应同时显示绝对变化。

## 数据不足

将可以回答、不能回答和需要补充的数据分开。补数清单要具体到字段、粒度、时间范围和来源，不只写“需要更多数据”。
