# 广告场景

在**应用-广告场景**页面可创建和编辑广告场景。在创建广告场景之前您必须先创建一个应用和至少一个广告位。

在广告场景页面，您可以做：

•添加广告场景

•查看广告场景数据

# **1**. 广告场景介绍

**1、 查看SDK加载及展示广告转化数据，提升收益**

通过使用广告场景功能，可以在[漏斗分析报表](https://newdocs.toponad.com/docs/qlHqYM) 查看SDK的各个广告加载和展示流程数据，判断广告设置是否合理，分析各个流程转化的优化空间，提升转化提高收益

**2、 减少广告位配置成本**

开发者通常用不同的广告位来区分不同广告场景的数据，这样可以有效的区分各个场景下的展示和收益数据，但同时会带来运营成本的增加（需要维护多个广告位的广告源配置）。

TopOn平台支持在广告位下创建多个广告场景，这样可以有效的区分不同广告场景下的展示、点击数据，降低用户配置广告位的成本。

# **2**. 广告场景接入流程说明

**1、当前广告位只对应一个广告场景：**

添加到达广告场景代码后，TopOn会在[综合报表](https://newdocs.toponad.com/docs/DVM3Tf)和[漏斗分析报表](https://newdocs.toponad.com/docs/qlHqYM) 提供以下核心指标，为您的广告变现提供更加完整的分析数据：

•SDK在到达广告场景时调用TopOn SDK的entryAdScenario()方法，可不传入广告场景ID，数据将分类到default广告场景

**2、当前广告位对应多个广告场景**，需要区分不同广告场景查看展示、点击数据：

•在TopOn后台创建广告场景 ，并可自定义广告场景ID

•在App里准确添加到达广告场景代码（调用TopOn SDK的entryAdScenario()方法并传入各个不同广告场景ID)

•展示广告时在show方法中传入scenarioId

# **4**. 创建广告场景及获取广告场景ID

若需要使用多个广告场景区分数据，可在后台创建广告场景并获取广告场景

1、应用->选择对应应用->查看广告位列表->场景管理



2、点击添加广告场景

•每个广告位均有Default默认场景，默认广告场景ID=""，调用到达广告场景方法时，不上传广告场景ID，数据将归到默认场景

•可自定义广告场景ID（TopOn SDK v6.2.48及以上版本支持），便于开发同学接入时区分广告场景；不填写广告场景ID将自动生成广告场景ID

•激励视频广告可以在广告场景中添加激励信息（激励名称和激励数量），激励信息会回调给开发者。具体可参考 iOS-回调信息说明 和 Android-回调信息说明



3、查看场景列表并获取广告场景ID，提供给开发同学接入使用

## 5.3 注意事项

1.**如果传入的广告场景ID错误或不是当前广告位下的广告场景ID，TopOn会将该部分数据统计到Default默认场景.**

2.**如果在entryAdScenario()、Show()方法不传入广告场景ID时，TopOn会将该部分数据统计到Default默认场景.**

3.**如果在entryAdScenario()、Show()方法传入暂停的广告场景ID时，TopOn会将该部分数据统计到Default默认场景.**

4.TopOn SDK不同版本支持广告场景的情况如：

| TopOn SDK版本 | 支持广告场景的广告类型 |
| --- | --- |
| >=5.4.7 | **激励视频**, **插屏** |
| >=5.7.9 (5.7.09) | **激励视频**, **插屏**, **原生**, **Banner**,**开屏** |

**支持TopOn后台自定义广告场景ID版本：>= v6.2.48**
