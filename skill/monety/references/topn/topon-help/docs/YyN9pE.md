## 1. 创建TopOn账号

(1) 进入TopOn官网账号注册页面：  [https://portal.toponad.net/m/register](https://portal.toponad.com/m/register)



(2) 依次填写注册信息

| 注册信息 | 填写说明 |
| --- | --- |
| 账号名称 | 输入账号名称。 |
| 注册邮箱 | 输入您的邮箱。 |
| 密码及确认新密码 | 输入密码不少于8位，需要包含大小写字母、数字、特殊符号，并进行密码的二次确认。 |
| 公司名称 | 输入您所在公司的名称。 |
| 联系人 | 输入公司联系人的信息。 |
| 手机号 | 输入您的手机号码，便于我们及时与您取得联系。 |
| 微信号 | 选填，输入您的微信号，便于我们通过微信及时与您取得联系。 |
| 币种 | TopOn提供【人民币】和【美元】两种货币单位统计，请选择你需要使用的货币单位。 |
| 产品类型 | 如您的应用是游戏类应用，请选择【游戏】；非游戏类应用请统一选择【应用】。 |
| 如何了解到TopOn | 选择您是通过什么途径了解到 TopOn 的。 |

(3) 勾选【我已阅读并同意TopOn用户服务协议和隐私政策】。

(4) 确认填写信息无误后，点击【注册】。

(5) 联系[TopOn商务经理](mailto:bussiness@toponad.com)进行账号激活。

(6) 登录[开发者后台](https://portal.toponad.net)进行聚合应用的配置： [https://portal.toponad.net/m/dashboard](https://portal.toponad.com)

> Tips：更多TopOn账号注册及管理问题请点击[TopOn账号管理](/cn/docs/HhRaEG)文档查看。>>[点击查看](/cn/docs/HhRaEG)

## 2. 添加应用和广告位

(1) 点击**【应用管理】-【添加应用】-【添加单个应用】**，创建您需要变现的应用程序



(2) 在弹出的弹框中依次填写应用相关信息



| 应用信息 | 填写说明 |
| --- | --- |
| 系统平台 | 选择应用操作系统。iOS / Android |
| App Store上架 / 应用商店上架 | 如您的应用已在 App Store / 应用商店 上架，则选择是；否则，选否。 |
| 应用商店 | 请选择上架的应用商店。 |
| 应用商店链接 | 填写您的应用在应用商店的链接地址，点击搜索后可自动识别应用名称、一级分类、二级分类、包名和图标。 |
| 应用名称 | 填写应用的名称。 |
| 一级分类 | 选择应用所属的一级分类。 如您的应用是游戏，则选择【游戏】；非游戏类请统一选择【应用】。 |
| 二级分类 | 选择应用所属的二级分类。 |
| Bundle ID | 填写iOS应用的Bundle ID。 |
| 应用屏幕方向 | 选择应用屏幕方向。 |
| 遵守美国COPPA | 选择“是”，表示该应用面向13周岁以下儿童，并且遵守美国的儿童在线隐私保护法相关规定。 |
| 遵守美国CCPA | 选择“是”，表示该应用遵守美国加利福尼亚州的消费者隐私法案相关规定，对该区域用户限制使用个人隐私数据 |

(3) 确认填写信息无误后，点击**【确定】**，保存应用信息。

(4) 配置成功后如图：



## 3. 添加广告位

(1) 在**【应用管理】**板块，点击需要添加广告位的应用，点击页面右上角**【添加广告位】。**



(2) 在弹出的弹框中依次填写广告位相关信息。

TopOn 后台提供的广告类型，与三方广告平台提供的广告类型对应关系，详见：[广告类型对应关系表](/cn/docs/SfGJi6)。



| 广告位信息 | 填写说明 |
| --- | --- |
| 应用 | 选择在哪个应用下添加广告位。 |
| 广告位名称 | 填写广告位名称。 |
| 广告类型 | TopOn后台支持五种广告类型的广告位配置，分别是： 开屏、原生（信息流）、Banner、插屏（插屏视频/插屏图片）、激励视频 |
| 状态 | 启用 / 暂停 |
| 服务端激励回调 | 激励视频广告类型可以设置服务端回调激励（默认关闭），在用户观看完成视频后，TopOn服务端会向您的服务器回调激励信息。TopOn SDK v5.7.56及以上版本支持。 注：为保障服务端激励的准确性，针对第三方广告平台建议开发者优先使用第三方广告平台的服务端激励回调。更多服务端激励回调内容[>>点击查看](/cn/docs/fu-wu-duan-hui-diao-gui-ze) |

(3) 确认填写信息无误后，点击**【确定】**，保存广告位信息。

(4) 配置成功后如图



## 4. 添加广告平台

(1) 根据实际需要，确定需要接入的广告平台并注册广告平台账号。可参考：[TopOn已聚合的平台概况。](/cn/docs/2KR6QU)

(2) 在TopOn后台**【广告平台】-【变现平台】**板块，添加已注册的广告平台。



(3) 在弹出的弹窗中，填写相关信息。



| 广告平台信息 | 填写说明 |
| --- | --- |
| 广告平台 | 在下拉列表中选择需要创建的广告平台。 |
| 账号名称 | 填写账号名称。默认填写：默认账号。 |
| 报表API | 已开通 / 未开通 ①选择已开通并填写相关参数，TopOn可以通过API将三方平台数据拉回并呈现在TopOn的各项报表中，帮助开发者全面了解您的广告业务变现效果。另外，带有【AUTO】字样的广告平台在开通报表API后可使用自动创建广告源的功能，提升开发者创建广告源的效率。 ②选择未开通，不会对广告变现产生影响 |
| 版本号 | 默认选2.0 |
| 自动创建广告源 | 是 / 否 选择报表API为已开通后，对于带有【AUTO】字样支持自动创建功能的广告平台，可选择是否开启该平台的自动创建广告源功能。 |
| 其他参数 | 填写报表API开通需要的各种参数，可点击左下角【如何找到这些参数？】获取指引。 |

(4) 确认填写信息无误后，点击**【确定】**，保存广告平台信息。

(5) 配置成功后如图：



## 5. 添加广告源

(1) 在**【聚合管理】**页面，选中对应的应用和广告位，点击页面左上角**【添加广告源】-【添加单个广告源】。**



(2) 在弹出的弹窗中选择对应的广告平台，填写相关参数，添加广告源。



① 各平台添加广告源指引可查看：[三方广告平台配置指南。](/cn/docs/A1g9gY)

② 其他信息填写说明如下：

| 广告源信息 | 填写说明 |
| --- | --- |
| 头部竞价 [>>了解更多](/cn/docs/dfnwQG) | ● 如需使用 头部竞价 请选择【是】，对应在广告平台创建的竞价广告源。 ● 竞价底价 ①竞价底价仅对服务端竞价生效，点击竞价底价后的小问号可查看支持的sdk版本； ②当广告平台出价低于竞价底价时TopOn会过滤此出价结果，设置竞价底价会降低竞价广告源的填充和收益，请谨慎设置； ③如果在流量分组和广告源同时设置了竞价底价，优先使用广告源的竞价底价； ● TopOn目前支持 Bidding 的广告平台请参见：[TopOn 支持 头部竞价 广告平台](/cn/docs/tou-bu-jing-jia-Bidding#2._TopOn%E6%94%AF%E6%8C%81%E7%9A%84%E5%A4%B4%E9%83%A8%E7%AB%9E%E4%BB%B7%E5%B9%BF%E5%91%8A%E5%B9%B3%E5%8F%B0) |
| 排序价格 [>>了解更多](/cn/docs/cXus5n) | ①排序价格**仅用于广告请求和展示时的优先级排序，不影响广告填充**。 ②建议排序价格与该广告源在广告平台设置的底价保持一致，可用于预估当天实时的收益和LTV。 ③无底价的广告源排序价格可以设置0.1，且开启自动价格。 |
| 兜底广告 [>>了解更多](/cn/docs/cXus5n#3._%E5%85%9C%E5%BA%95%E5%B9%BF%E5%91%8A) | ①广告源设置为兜底广告后，不可更改。 ②兜底广告与Waterfall实行错峰并行策略，缩短广告的填充耗时。 ③当瀑布流请求没有填充时，TopOn将使用兜底广告展示。当瀑布流请求有填充时，TopOn按排序价格的高价进行展示。 |
| 自动价格 [>>了解更多](/cn/docs/cXus5n) | ①使用前提：需要开通广告平台的报表 API权限 ②开启之后，TopOn将根据广告平台过去7天的平均eCPM来计算排序价格。当数据过少时（展示少于2000），TopOn仍使用人工填写的排序价格进行排序 |

(3) 确认填写信息无误后，点击**【确定】**，保存广告源信息。

(4) 配置成功后如图：



## 6. 集成TopOn SDK和三方广告平台的SDK

(1) 下载地址： [https://portal.toponad.net/m/sdk/download](https://portal.toponad.com/m/sdk/download)



(2) 开发者根据需要选择TopOn SDK版本和需要接入的广告平台SDK。

**注：由于各广告平台可支持的广告类型不同，开发者可在广告样式栏勾选需要的广告样式，系统会自动筛选出可用的广告平台，并高亮显示。**

如下图，勾选【原生】广告样式后，部分广告平台置灰，表示该广告平台暂不支持原生广告。



(3) 勾选需要接入的广告平台后，点击**【生成接入代码】。**



(4) 根据集成指南进行SDK集成

| --- | --- |
| Android 接入指南 | [>>点 击查看](/cn/docs/Android) |
| iOS 接入指南 | [>>点击查看](/cn/docs/iOS) |
| Unity 接入指南接入 | [>>点击查看](/cn/docs/Unity) |
| Flutter 接入指南 | [>>点击查看](/cn/docs/flutter) |
| React Native 接入指南 | [>>点击查看](/cn/docs/reactnative) |
| Cocos2dx 接入指南 | [>>点击查看](/cn/docs/Cocos2dx) |

(5) 获取SDK集成时需要用到的参数：**App Key**、**App ID（应用ID）**、**Placement ID（广告位ID）**、**Senario ID（广告场景ID）**（广告场景ID非必须，可自行选择是否配置）

## 8. 数据分析及效果优化

恭喜您成功集成了TopOn SDK, 可以开始创收啦！ 应用发布后，可以在数据报表中查看数据效果，进行数据分析，以及参考TopOn为您提供的**广告分层入门和优化技巧**开始变现之旅。

- **数据报表**：提供了丰富的广告变现侧的数据维度，以全面了解您的广告业务变现效果。[>>点击查看](/cn/docs/50CPod)
- **广告分层入门和优化技巧**：TopOn为您提供广告分层入门介绍和优化技巧，帮助您提升变现收益。[>>点击查看](/cn/docs/eUCSzO)
