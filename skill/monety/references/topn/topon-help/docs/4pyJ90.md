# Chartboost

## Step1. 创建Chartboost账号

[**注册并登录**](https://dashboard.chartboost.com/login)Chartboost账号

## Step2. 创建Chartboost应用和广告单元

**(1) 添加应用**
注：应用必须在AppStore或Google play上架才可使用Chartboost创收。





**(2) 添加广告单元**
根据应用广告场景需要创建对应的广告单元类型。





## Step3. 开通Chartboost的Report API

**(1) 开通Chartboost的Report API需要获取User ID和User Signature两个参数。**

① 进入Mediation 界面（跳转helium）



② 点击API Explorer

③ 查看User ID和User Signature



**(2) 在Topon开发者后台开通Chartboost的Report API**

① 填写User ID（用户ID）和User Signature（用户签名）
② 登录Topon后台→广告平台→变现平台→添加广告平台（Chartboost & Helium）→编辑（开通报表API）



## Step4. Topon平台配置Chartboost广告位说明

Chartboost的广告场景跟Topon的广告类型对应关系如下表

##

| Chartboost-广告类型 | Topon-广告类型 |
| --- | --- |
| Rewarded | 激励视频 |
| Interstitial | 插屏 |
| Banner | Banner |

(更多Topon支持聚合的广告平台，其广告类型与Topon后台配置的广告类型，对应关系速查可见此[汇总文档](https://help.toponad.net/cn/docs/SfGJi6))

## Step5. 在Topon开发者后台上绑定Chartboost

(1) 以下Chartboost的3个参数需要配置在Topon开发者后台才能通过Topon展示Chartboost广告以及通过Topon开发者后台展示Chartboost的数据：

① **App id**和**App signature**



选择应用后查看App id和App signature



**② Ad Location**

进入Set up Monetization查看**Ad Loaction Name**





**(2) 将Chartboost的参数配置在Topon开发者后台**

添加广告源

① 登录TopOn后台→广告平台→变现平台→广告源管理（Chartboost）→添加广告源

② 填写TopOn应用对应的Chartboost应用的**App id/App signature/Ad Location**

| 参数名称 | 说明 |
| --- | --- |
| 应用 ID | Chartboost每个应用对应的唯一的**APP ID** |
| 应用签名 | Chartboost每个应用对应的唯一的**App signature** |
| Ad Location | Chartboost每个广告位对应的**Ad Loaction Name** |
