# TopOn ADX

# 1. 什么是TopOn ADX？

ADX为Ad Exchange的简称。Ad Exchange即互联网广告交易平台，它联系着DSP（买方平台）和SSP（卖方平台），是实现精准营销的交易场所。
TopOn ADX是TopOn的自有广告资源，对接了多家DSP，为开发者提升广告变现收益作进一步的支持和补充。
TopOn ADX类似头部竞价（Header Bidding）功能，允许TopOn ADX针对同一个广告展示竞价，最高出价者获得展示机会，这确保发布商的每次展示可以获得更高的收益。

# 2. TopOn ADX的优势和使用场景

- **提升广告填充和eCPM**：当前接入的广告平台无法满足足够的广告填充和eCPM，通过TopOn ADX获取更多的广告预算。例如，大多数情况下，TopOn ADX参与到开发者瀑布流中所有广告源的竞价和广告填充。
- 举一个极端情况下提升广告填充机会的例子，开发者当前接入了A和B两家广告平台，整体流量填充率为95%，即发起100个的广告请求时，广告平台A和B能对95%的流量请求进行填充（在这95个请求当中，TopOn ADX也参与了竞价，在实际竞价过程中，价高者获得展示机会），剩下的5%的请求广告平台A和B都没有出价，决定不填充；TopOn ADX能对剩余的5%的广告请求进行竞价填充，提升整体的流量填充率和收益，减少广告浪费。注意这里仅为极端情况下的举例，在实际情况当中，TopOn ADX的上游广告主可能不会对这5%里面的全部请求都进行填充。大量已接入开发者验证，打开TopOn ADX，应用的整体流量填充率和人均收益均有不同程度提升。
- **开发者自有广告资源**：若您与外部的DSP有直接的合作或者有自己的广告资源库，可以通过TopOn ADX功能直接接入。

# 3. TopOn ADX注意事项及TopOn ADX如何结算

### 3.1 结算事项

- 因TopOn ADX功能涉及到付款事宜，**需联系TopOn商务签署合同后才能进行结算**；
- TopOn ADX的收益表现以TopOn开发者后台数据（即：数据报表-综合报表-筛选广告平台为TopOn ADX）为准。

### 3.2 app-ads.txt事项

- 对于希望在海外流量上变现的开发者，我们**强烈建议**在打开TopOn ADX时，在[TopOn开发者后台- ADX设置 - app-ads.txt](https://portal.toponad.net/m/adx/set/app-ads)页面，填写您的域名和公司名称，并在对应域名的根目录下**部署app-ads.txt**。广告网络或DSP也将通过该网站验证app-ads.txt文件，从而能**获取更多预算**。具体操作说明可参考[该文档](https://help.toponad.net/cn/docs/appadstxt_and_sellersjson)。
- 对于变现流量大部分在中国国内的开发者，则无须进行相关操作。

### 3.3 TopOn ADX 集成

如您采用TopOn 聚合SDK，则无需SDK单独接入TopOn ADX，在开发者后台可直接开启使用，不需要另外发版。

如您采用其他聚合平台，希望接入TopOn ADX进行变现，可参考以下文档：

- 自建聚合集成： [TopOn ADX 客户端出价集成](/cn/docs/TopOn-Adx-ke-hu-duan-chu-jia-ji-cheng)
- 通过MAX聚合集成： [MAX集成TopOn](/cn/docs/Android-Max-jie-ru-TopOn-Adapter-shuo-ming)
- 通过IronSource聚合集成： [IronSource集成TopOn](/cn/docs/Android-ironSource-jie-ru-TopOn-Adapter-shuo-ming)

# 4. 如何打开TopOn ADX

在**聚合管理**页面，在您的广告位下开启TopOn ADX开关即可使用。



另外，为了提高您设置TopOn ADX的效率，TopOn提供了**默认配置**及**批量开关**的功能，您可以批量开启关闭TopOn ADX（路径：**高级功能 > TopOn ADX设置 > 开关**）



- **默认开关**：新增TopOn广告位或新增流量分组时，对所勾选的样式默认打开TopOn ADX
- **批量操作**：支持批量开启或关闭当前页面选中的全部流量分组下的TopOn ADX广告源

# 5. 如何设置TopOn ADX

## 5.1 TopOn ADX的应用配置

TopOn ADX提供了**应用层级的配置**的功能，您可以配置TopOn ADX的**包名黑名单**（路径：**高级功能 > TopOn Adx设置 > 配置**）



**1、配置类型**支持遵循全局配置 或 遵循单独配置 ：

- **全局配置**：针对全局的App效（有单独配置的App除外）
- **单独配置**：针对单独的App生效

**2、配置**支持选项： **包名黑名单**

- **下载APK类广告二次确认**：当TopOn ADX投放下载APK类广告时，您可能此选择控制是否进行下载前的二次确认。为确保符合政策规定，自SDK v6.2.77 起，下载广告的二次确认弹窗将不再支持自定义调整。
- **包名黑名单**：您可以填写需要TopOn ADX过滤的Android包名(例如：com.toponad.demo) 或 iOS App Stores ID(示例：id12345678)



## 5.2 TopOn ADX的广告位属性配置

TopOn ADX提供**广告位属性**的配置能力，您可以单独设置TopOn ADX 广告源的属性，也可以批量设置TopOn ADX的属性。

### **5.2.1 配置入口：**

- 单独设置TopOn ADX 广告源属性：不同流量分组需要单独设置。路径：**聚合管理 > TopOn ADX > 编辑**
- 批量设置TopOn ADX的属性：路径：**高级功能 > TopOn ADX设置 > 开关 > 批量操作**

# 常见问题

### 1）TopOn ADX有什么用，打开有什么好处？

请参考以上第2点，TopOn ADX的优势和使用场景。

### 2）必须要打开TopOn ADX吗，不打开会有什么影响？

TopOn是公正中立的第三方聚合，TopOn ADX的广告预算为TopOn对接的上游广告主资源。 这部分预算不会强制开发者打开，开发者可以根据自身广告变现情况，自行评估并且选择是否打开TopOn ADX的开关，决定是否要接入。

### 3）TopOn ADX应该如何打开，需要发版更新吗？

不需要发版更新，直接在聚合管理页面打开即可，参考下述第4步。 结算事宜：需要联系您的TopOn商务或运营经理进行合同签署。

### 4）TopOn ADX的填充率和eCPM表现是怎样的？

**关于TopOn ADX的eCPM**：

①首先明确TopOn ADX的定义：

TopOn ADX是TopOn的自有广告资源，对接了多家DSP，为开发者提升广告变现收益作进一步的支持和补充。 TopOn ADX类似头部竞价（Header Bidding）功能，允许TopOn ADX针对同一个广告展示竞价，最高出价者获得展示机会，这确保发布商的每次展示可以获得更高的收益。

这决定了TopOn ADX的预算来源。因此，TopOn ADX的实际eCPM出价，一方面由上游广告主的出价决定，一方面由平台用户的广告行为质量决定（例如平台用户的点击率和后续转化等一系列指标）。

②由于竞价充分、市场信息完整，整体上来说，TopOn ADX的eCPM出价，一般不低于当地该品类大盘的出价，接近或大于当地该品类大盘均价。 例如，某中国图文影音类开发者开屏eCPM为20元，那么，TopOn ADX eCPM在该位置的整体均价会处于15-30的范围。（均价为15-30的范围，实际上每次的出价，依然会根据当前上游广告主对每次发起流量请求的用户广告质量进行判断。）

**关于TopOn ADX的填充率**：

实际上，由于TopOn ADX类似头部竞价（Header Bidding）功能，允许TopOn ADX针对同一个广告展示竞价，最高出价者获得展示机会，这确保发布商的每次展示可以获得更高的收益。

对于每一次应用发起的流量请求，TopOn SDK都会发起对TopOn ADX上游广告主的竞价，根据上游广告主的竞价响应率和竞价响应eCPM进行后续的广告竞价。

因此，TopOn ADX的竞价响应率和广告填充率整体上来说都能达到90%以上。部分T3地区（例如沙特、突尼斯等地区）会由于上游广告主预算较少或是网络原因，竞价响应率较低。
