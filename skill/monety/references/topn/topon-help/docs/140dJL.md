# 用户行为报表

## 1. 功能概述

数据报表下拉后可进入用户行为报表，用户行为报表包括使用时长和展示频次两部分



## 2. 操作指引

### 2.1 展示频次报表

**(1) 内容概况**

使用时长报表支持日期、应用、广告位、地区和渠道5个维度的展示频次数据统计。支持查看展示频次的时间变化趋势，和不同频次之间的分布比例。详细数据部分还支持查看每日频次明细，支持数据报表导出。



**(2) 相关数据说明**

报表涉及到的筛选项及指标说明如下：

| 筛选项 | 说明 |
| --- | --- |
| 日期 | 数据产生的时间段。**注意**：每次最多选择30天的日期。 |
| 应用 | 在TopOn创建的应用。 [>>更多](/cn/docs/pzi00q) |
| 广告位 | 在TopOn创建的广告位。 [>>更多](/cn/docs/pzi00q#2._%E5%B9%BF%E5%91%8A%E4%BD%8D%E7%AE%A1%E7%90%86) |
| 地区 | 用户所在的国家/地区 |
| 渠道 | 开发者可将渠道字段传至TopOn,以便区分用户不同来源渠道的数据。 [>>如何通过自定义规则传渠道字段？](/cn/docs/KjVUSq#3._TopOn_SDK%E8%AE%BE%E7%BD%AE%E6%B5%81%E9%87%8F%E5%88%86%E7%BB%84%E8%87%AA%E5%AE%9A%E4%B9%89%E8%A7%84%E5%88%99) |

| 数据指标 | 说明 |
| --- | --- |
| 展示频次 | 在选择的时间内，显示展示了1到100次+广告对应的设备数据。若展示频次=1次，对应行的数据标识在当前选择的时间内，只展示了1次广告的设备数量，以及这些设备对应的展示、预估收益数据。 |
| 设备数 | 每行均对应展示了n次广告的设备总数量，根据设备信息去重。 |
| 设备占比 | 当前展示频次的设备数/总设备数。 |
| 展示 | 从2023年3月7日 0点（UTC+8）起，统计口径从“TopOn调用广告平台SDK开始展示的次数”调整为“TopOn收到广告平台SDK展示成功的回调次数”。由于统计口径不一样，TopOn统计的展示与广告平台统计的展示（展示API）可能存在一定差异。 |
| 展示占比 | 当前展示频次对应设备的展示数/总展示数 |
| 预估收益 | 根据TopOn SDK统计的展示数和eCPM价格进行预估的收益。计算公式：①常规广告源：人工填写的eCPM价格\*TopOn统计的展示/1000；②头部竞价广告源：实时的广告展示价格。[>>头部竞价说明](/docs/dfnwQG) |
| 预估收益占比 | 当前展示频次对应设备的预估收益汇总/总预估收益 |
| eCPM | 预估收益/展示 \*100% |

### 2.2 用户价值报表

**(1) 内容概况**

用户价值报表支持查看具体时间、应用、广告位、地区、渠道的所有展示的eCPM数据。支持显示不同eCPM范围的具体每次展示的收益分布情况，快速定位到开发者在哪个eCPM范围展示的次数最多，并且通过预估收益累计占比协助判断应该如何配置用户价值流量分组的区间数据。



**(2) 相关数据说明**

报表涉及到的筛选项及指标说明如下：

| 筛选项 | 说明 |
| --- | --- |
| 日期 | 数据产生的时间段。**注意**：每次最多选择30天的日期。 |
| 应用 | 在Topon创建的应用。 [>>更多](/cn/docs/pzi00q) |
| 广告位 | 在Topon创建的广告位。 [>>更多](/cn/docs/pzi00q#2._%E5%B9%BF%E5%91%8A%E4%BD%8D%E7%AE%A1%E7%90%86) |
| 地区 | 用户所在的国家/地区 |
| 渠道 | 开发者可将渠道字段传至Topon,以便区分用户不同来源渠道的数据。 [>>如何通过自定义规则传渠道字段？](/cn/docs/KjVUSq#3._TopOn_SDK%E8%AE%BE%E7%BD%AE%E6%B5%81%E9%87%8F%E5%88%86%E7%BB%84%E8%87%AA%E5%AE%9A%E4%B9%89%E8%A7%84%E5%88%99) |
| eCPM范围 | 此筛选项不影响当前页面的数据结果，当前页面显示的数据仅受上面的几个筛选项的影响。选择不同的eCPM范围，仅会影响下面图和表的数据汇总到哪个区间。  例如：选择eCPM范围为0-50，下面图和表的最大eCPM区间将显示到50，超过50 eCPM的所有展示数据将全部汇总在[50,50+]这个区间里面。  **建议选项：**如果您发现您的数据大部分集中在最大的eCPM区间，请选择更大的eCPM范围 |

| 数据指标 | 说明 |
| --- | --- |
| 展示数 | 对应某个区间的的所有展示数。例如：[0,1)的eCPM范围，对应的展示数是eCPM在0到1中间的广告展示的累计数据。 |
| 展示占比 | 计算公式=对应区间的展示数/当前筛选条件下的总展示数\*100% |
| 设备数 | 对应某个区间的的所有设备数。例如：[0,1)的eCPM范围，对应的展示数是eCPM在0到1中间的广告展示的去重设备。 |
| 设备占比 | 计算公式=对应区间的设备数/所有区间的设备数求和\*100%，注意，此处不同区间设备求和不去重。 |
| 预估收益 | 对应某个区间的的所有展示数对应的预估收益总和。 |
| 预估收益占比 | 计算公式=对应区间的预估收益/当前筛选条件下的总预估收益\*100% |
| 预估收益累计占比 | 从0开始到当前eCPM范围的累计预估收益占总预估收益的占比。  计算公式：求和0到当前区间的所有eCPM范围的预估收益/当前筛选项下所有的总预估收益\*100%。  例如：[4,5)对应的预估收益累计占比，需要求和[0,1)、[1,2)、[2,3)、[3,4)、[4,5)这些eCPM区间的预估收益占比。 |

### 2.3 使用时长报表

**(1) 内容概况**

使用时长报表支持日期、应用、地区和渠道4个维度的使用时长数据统计。支持人均使用时长、人均会话次数和单次使用时长的曲线图表对比，详细数据部分还支持查看每日用户会话次数、展示/会话次数，支持数据报表导出。



**(2) 相关数据说明**

报表涉及到的筛选项及指标说明如下：

| 筛选项 | 说明 |
| --- | --- |
| 日期 | 数据产生的时间段。**注意**：每次最多选择30天的日期。 |
| 应用 | 在TopOn创建的应用。 [>>更多](/cn/docs/pzi00q) |
| 地区 | 用户所在的国家/地区 |
| 渠道 | 开发者可将渠道字段传至TopOn,以便区分用户不同来源渠道的数据。 [>>如何通过自定义规则传渠道字段？](/cn/docs/KjVUSq#3._TopOn_SDK%E8%AE%BE%E7%BD%AE%E6%B5%81%E9%87%8F%E5%88%86%E7%BB%84%E8%87%AA%E5%AE%9A%E4%B9%89%E8%A7%84%E5%88%99) |

| 数据指标 | 说明 |
| --- | --- |
| 会话次数 | 每次启动应用到关闭应用，包括冷启动和热启动，均会被记作一次会话数。 |
| 展示/会话次数 | 平均每次会话的广告展示次数 |
| 人均会话次数 | 平均每个用户一天内启动应用的次数。计算公式：总启动次数/DAU |
| 人均使用时长 | 平均每个用户一天内使用该应用的时长。计算公式：全部用户的日使用时长/DAU |
| 单次使用时长 | 平均每个用户每次会话的时长。计算公式：全部用户的日使用时长/总启动次数 |
