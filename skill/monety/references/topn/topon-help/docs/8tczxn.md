# 交叉推广广告素材管理说明

## 1. 说明概述

交叉推广支持多种的广告样式，包括：**激励视频、插屏视频、插屏图片、原生、开屏、Banner**。

针对不同的广告类型需要配置的素材有所差异，您需要按以下素材要求配置广告素材。

## 2. 激励视频和插屏视频

**(1) 激励视频**和**插屏视频**广告素材要求如下：

| 素材内容 | 是否必填 | 内容要求 | 示例 |
| --- | --- | --- | --- |
| 素材标题 | 是 | 50个字符 | MyGame |
| 素材描述 | 是 | 50个字符 | Let's Play MyGame |
| 按钮方案 | 是 | 20个字符 | Install Now |
| ICON图片 | 是 | 推荐尺寸：200x200以内的方形图，大小不超过200KB，格式：png、jpg、jpeg | - |
| 竖版视频下载链接 | 竖版或横版至少二选一 | **必须为可下载的MP4文件**，建议时间长度为30秒 特别注意：链接地址不能包含任何中文字符，MP4文件名称只能使用英文字母、数字和下划线 | <http://cdn.abc.com/abc.mp4> |
| 竖版大图 | 竖版或横版至少二选一 | 推荐尺寸：1080x1920、720x1280、768x1024，大小不超过1MB，格式：png、jpg、jpeg | - |
| 横版视频下载链接 | 竖版或横版至少二选一 | **必须为可下载的MP4文件**，建议时间长度为30秒. 特别注意：链接地址不能包含任何中文字符，MP4文件名称只能使用英文字母、数字和下划线 | <http://cdn.abc.com/abc.mp4> |
| 横版大图 | 竖版或横版至少二选一 | 推荐尺寸：1920x1080、1280x720、1024x768，大小不超过1MB，格式：png、jpg、jpeg | - |
| 显示品牌Logo | 否 | 关闭后不显示TopOn Logo | - |

(2) 如果您同时配置了竖版和横版的素材，Topon SDK 会根据用户当前的屏幕方向选择最优的素材进行展示。

## 4. 原生

(1) 原生广告素材要求如下：

| 素材内容 | 是否必填 | 内容要求 | 示例 |
| --- | --- | --- | --- |
| 素材标题 | 是 | 50个字符 | MyGame |

### 5.2 开屏广告源配置

您可以在**聚合管理**的**交叉推广**广告源，编辑开屏广告的交互配置。目前开屏广告的支持以下配置项：



| 配置项 | 可选项 | 默认值 |
| --- | --- | --- |
| 屏幕方向 | 竖屏 或 横屏 | 竖屏 |
| 倒计时时间 | - | 5秒 |
| 可跳过 | 打开 或 关闭 | 打开 |
| 样式类型 | **拼接样式** 或 **全屏大图** | 拼接样式 |

## 6. Banner

### 6.1 Banner素材要求

(1) Banner广告素材要求如下：

| 素材内容 | 是否必填 | 内容要求 | 示例 |
| --- | --- | --- | --- |
| 素材标题 | 是 | 50个字符 | MyGame |
| 素材描述 | 是 | 50个字符 | Let's Play MyGame |
| 按钮方案 | 是 | 20个字符 | Install Now |
| ICON图片 | 是 | 推荐尺寸：200x200以内的方形图，大小不超过200KB，格式：png、jpg、jpeg | - |
| 横版大图 | 是 | **推荐尺寸：1200x627**，大小不超过1MB，格式：png、jpg、jpeg | - |
| 横幅(320x50) | 否 | 推荐尺寸：320x50、640x100，大小不超过1MB，格式：png、jpg、jpeg | - |
| 大横幅(320x90) | 否 | 推荐尺寸：320x90、640x180，大小不超过1MB，格式：png、jpg、jpeg | - |
| 中矩形横幅(300x250) | 否 | 推荐尺寸：300x250、600x500，大小不超过1MB，格式：png、jpg、jpeg | - |
| 首页横幅(728x90) | 否 | 推荐尺寸：728x90、1456x180，大小不超过1MB，格式：png、jpg、jpeg | - |
| 显示品牌Logo | 否 | 关闭后不显示TopOn Logo | - |

(2) TopOn SDK在展示Banner广告时，会优先使用相应Banner尺寸的图片。如果相应Banner尺寸没有配置图片时，TopOn SDK会采用基本素材拼接Banner广告。

### 6.2 Banner广告源配置

您可以在**聚合管理**的**交叉推广**广告源，**编辑**Banner广告的配置。目前Banner广告的支持以下配置项：



| 配置项 | 可选项 | 默认值 |
| --- | --- | --- |
| 广告源尺寸 | 横幅(320x50) 大横幅(320x90) 中矩形横幅(300x250) 首页横幅(728x90) | 横幅(320x50) |
| 关闭按钮 | 打开 或 关闭 | 打开 |
