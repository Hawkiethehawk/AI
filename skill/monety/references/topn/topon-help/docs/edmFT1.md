# 分小时报表

## 1. 功能概述

(1) 最多可支持5个独立日期对比。

(2) 支持勾选需要的指标，查看可视化图表。

(3) 图表可导出。





## 2. 相关数据说明

### 2.1 数据筛选项

| 筛选项 | 说明 |
| --- | --- |
| 日期 | 数据产生的时间段 **注意**：每次最多选择7天的日期 |
| 应用 | 在TopOn创建的应用。 [>>更多](/cn/docs/pzi00q#1._%E5%BA%94%E7%94%A8%E7%AE%A1%E7%90%86) |
| 广告位 | 在TopOn创建的广告位。 [>>更多](/cn/docs/pzi00q#2._%E5%B9%BF%E5%91%8A%E4%BD%8D%E7%AE%A1%E7%90%86) |
| 广告场景 | 广告场景是在一个广告位下创建多个广告场景，可以有效的区分不同广告场景下的展示、点击数据。适用于应用内有多个广告场景同时需要区分展示数据的产品。[>>更多](/cn/docs/pzi00q#3._%E5%B9%BF%E5%91%8A%E5%9C%BA%E6%99%AF) |
| 广告样式 | 在TopOn创建的广告位对应的广告样式：激励视频、插屏、原生、开屏、Banner |
| 流量分组 | TopOn提供多个维度对用户进行分组，不同的流量分组可以配置不同的Waterfall，以实现精细化流量变现。目前TopOn支持的流量分组维度具体如下： 地区，广告样式，应用，广告位，日期，小时，网络类型，应用版本，SDK版本，设备类型，设备品牌，安装时间，渠道，子渠道和自定义规则   [>>更多](/cn/docs/KjVUSq) |
| 渠道 | 开发者可将渠道字段传至TopOn,以便区分用户不同来源渠道的数据   [>>如何通过自定义规则传渠道字段？](/cn/docs/KjVUSq#3._TopOn_SDK%E8%AE%BE%E7%BD%AE%E6%B5%81%E9%87%8F%E5%88%86%E7%BB%84%E8%87%AA%E5%AE%9A%E4%B9%89%E8%A7%84%E5%88%99) |
| 广告平台 | TopOn支持的多家广告平台SDK的接入。 [>>TopOn支持的广告平台](/cn/docs/2KR6QU) |

| SDK版本 | TopOn的SDK版本 [>>SDK下载地址](https://portal.toponad.net/m/sdk/download) |

| 系统平台 | 安卓/IOS |

### 2.2 数据指标

分小时报表支持的数据指标。

| 数据指标 | 说明 |
| --- | --- |
| 日期 | 数据产生的时间段 |
| 小时 | 当天所属的小时时间段 |
| 预估收益 | 根据TopOn SDK统计的展示数和eCPM价格进行预估的收益。计算公式：①常规广告源：人工填写的eCPM价格\*TopOn统计的展示/1000；②头部竞价广告源：实时的广告展示价格  [>>头部竞价说明](/cn/docs/dfnwQG) |
| 预估eCPM | 根据预估收益和TopOn统计的展示计算出预估eCPM，计算公式：（预估收益/TopOn统计的展示）\*1000。注：1、预估 eCPM当天提供；2、常规广告源基于手动填写的eCPM价格计算，竞价广告源基于实时竞价价格计算 |
| 流量请求 | 应用（客户端）向TopOn SDK发起的请求（Load)次数 |
| 流量填充率 | 应用（客户端）向TopOn SDK发起请求（Load）后，广告返回成功的占比。计算公式：流量请求返回成功数（流量填充数）/流量请求\*100% |
| 广告源请求 | TopOn按照聚合管理的瀑布流广告源排序向各广告平台（广告源）发起的请求次数 **注意**：一次流量请求可能会对应多次广告源请求。当应用（客户端）向TopOn发起请求时，TopOn按照瀑布流广告源排序依次向各广告源发起请求，当高优先级的广告源没有填充、或者短超时（8s）内还没有广告返回，则会往下请求低优先级的广告源，此时一次流量请求会对应多次广告源请求 |
| 广告填充率 | TopOn向各广告平台（广告源）发起请求后，广告返回成功的占比。计算公式：广告源请求返回成功数（广告填充数）/广告源请求\*100% |
| 展示 | 从2023年3月7日 0点（UTC+8）起，统计口径从“TopOn调用广告平台SDK开始展示的次数”调整为“TopOn收到广告平台SDK展示成功的回调次数”。由于统计口径不一样，TopOn统计的展示与广告平台统计的展示（展示API）可能存在一定差异 |
| 展示率 | TopOn统计的广告曝光次数占流量请求返回成功数（流量填充数）的比例。计算公式：展示/流量填充数\*100% |
| 点击 | TopOn统计的广告点击数。部分平台不提供点击回调（如Admob的激励视频），导致TopOn无法统计到用户的点击行为 |
| 点击率 | TopOn统计的广告点击数占TopOn统计的广告曝光次数的比例。计算公式：点击/展示\*100% |

## **3. 常见问题**

**(1) 分小时报表适用场景**

① 观察策略/设置等调整后的数据变化。

② 观察不同时间段的数据表现。

③ 实时预估当天的收益表现，以提供买量支撑。

**(2) 分小时报表的数据如何统计的**

① 收益相关的数据指标，如预估收益、预估eCPM是依赖于开发者填写的eCPM排序价格预估的，因此填写的价格越接近实际eCPM，则预估数据越准确。

② 除收益相关的数据指标以外的数据均为TopOn SDK埋点统计数据。
