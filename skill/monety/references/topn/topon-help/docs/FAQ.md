# FAQ

## **常见问题**

**(1) TopOn如何收费，营利方式是什么？**

使用TopOn的聚合产品以及对应服务都是完全免费的，TopOn不收取任何平台中间差价。

TopOn的盈利主要来源于产品私有化服务定制，高级代运营服务提供，以及TopOn ADX在Bidding竞价成功后获得的相应收入等等，更多增值服务请联系TopOn商务运营团队。
