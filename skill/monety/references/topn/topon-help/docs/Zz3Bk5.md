# 广告平台

## 1. 什么是广告平台

在**广告平台**页面，您可以选择并添加合适您产品流量的广告平台，TopOn支持您向多个广告平台发出请求，以帮助您实现广告变现收益最大化。



在广告平台页面，您可以做：

- 添加/编辑广告平台
- 广告平台多账号配置
- 查看广告平台数据
- 广告源管理

## 2. 如何操作广告平台

### 2.1 添加/编辑广告平台

广告平台的选取需要结合产品流量地区分布、广告类型等多角度考虑，如有疑问可联系我们协助提供建议。

**点击左上角【+广告平台账号】进入添加广告平台页面**

(1) 选择广告平台

支持自动创建广告源的平台将显示AUTO标识



(2) 选择是否开通报表API。

- 建议全部开通报表API，可用于数据的及时拉取以及使用自动优化排序功能。
- 针对中国大陆部分广告平台账号如无报表API权限，可暂时选择未开通。
- 填入平台账号参数，参考左下角的 “如何找到这些参数？”引导。

### 2.2 广告平台多账号配置

一个TopOn账号可绑定同一个广告平台多个账号，可设置多个账号的Reporting API。

**如：**一个TopOn账号可绑定2个Admob账号

(1) 广告平台→添加广告平台

同个广告平台添加多个账号时，请自定义账号名称以便区分。



(2) 创建好后可看到一个平台对应了两个广告平台账号



(3) 选择广告平台账户并点击“广告源管理”进入添加广告源页面完成广告源参数配置。

### 2.3 查看广告平台数据

游戏上线后可在此页面查看直观地查看广告平台数据，指标有：收益、展示API、点击API、点击率API。



### 2.4 广告源管理

添加广告平台之后，可以点击进入对应的广告源管理页面，在此页面可添加和编辑三方平台应用ID（**编辑**三方广告平台应用ID仅可在此页面）以及添加、编辑、删除三方广告源。



**添加广告源**

(1) 选择对应的广告平台并进入广告源管理页面。

(2) 添加账号名称/应用ID等参数信息。

- 不同平台参数信息不同。
- 应用ID指在广告平台后台创建应用后对应的应用ID，每家广告平台叫法可能有所不同，比如Faecbook叫应用编号。
- 如何获取对应参数？请按照页面提示参阅文档即可。



(3) 添加广告源并填写对应参数，如广告位ID。

- 广告位ID指在广告平台后台创建的广告位ID，不同广告平台叫法有所不同。
- 如何获取对应参数？请按照页面提示参阅文档即可。



**同一时间如需添加多个广告源可使用【批量添加】功能**



(4) 价格填写。

可针对不同流量分组设置不同价格



(5) 点击确认。

展示上限、展示间隔不是必填项，此页面可默认不填。

## 3. 常见问题

**(1) 新版本新增了广告平台，是否会影响老版本的用户？**

不会。若老版本用户的waterfall里配置了新增广告平台的广告源，则会直接跳过该广告源继续往下请求。

**(2) Report API（报表API）是必须开通的吗？**

- 如果支持开通的平台最好都开通，不开通的话收益就回传不到TopOn后台了。
- 部分国内平台report API权限比较难拿到的话可以暂时先不开通，后续手动上传即可。
