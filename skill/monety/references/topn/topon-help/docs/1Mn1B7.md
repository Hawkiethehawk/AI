# TopOn隐私政策

2026年3月29日更新

## 1. 简介

a) 如果您是美国公民或根据美国法律合法成立的实体，则本协议是您与Ascent Pro Technology Limited之间订立的；

b) 如果您不是a)中指定的国家或地区的公民或实体，也不是中国大陆或香港特别行政区（HKSAR）公民或根据这些国家或地区的法律合法成立的实体，则本协议是您与TOPON PTE. LTD.之间订立的。

在本协议中，除非另有说明，Ascent Pro Technology Limited和TOPON PTE. LTD.合称为“TopOn”。如果您代表公司处理并签署本协议，您应确保您已获得公司合法有效的授权。在本协议中，TopOn和合作方分别称为“一方”，合称为“双方”或“各方”。

(1) **我们在提供服务时获取的个人信息**，包括（i）我们通过软件开发工具包（“SDK”）、应用程序编程接口（“API”）、我们的平台、服务或技术从移动应用开发商、广告交易平台、供应方平台、中介平台等流量供应伙伴处收集的有关终端用户的设备个人信息；（ii）通过我们的SDK、API或其他技术收集的，或者由我们的业务合作伙伴（如移动应用开发商、广告商，以下简称“业务合作伙伴”）或其指定的第三方收集并传输给我们的有关终端用户与广告互动的个人信息；（iii）终端用户使用我们业务合作伙伴的移动应用、网站、平台或服务过程中产生的设备个人信息以及我们的业务合作伙伴或其指定的第三方收集并传输给我们的个人信息；（iv）业务合作伙伴在使用TopOn的平台、技术、服务时提供的个人信息。在TopOn服务的隐私政策中，本节中提到的终端用户统称为“用户”、“您”或“您的”；本节中提及的SDK、API、 TopOn提供的任何技术、平台或服务均称为“ TopOn服务”。

## 2. 我们如何以及为何收集用户个人信息

本隐私政策描述了TopOn在以下场景中的个人数据收集和个人数据使用行为：

TopOn服务或任何TopOn商业合作伙伴所提供的服务的性质，我们可能直接或通过我们的商业合作伙伴（如：移动应用开发商、程序化广告交易所、广告聚合平台、广告需求方平台、流量提供方平台）收集个人数据。例如：

（1） 当我们为移动应用开发者提供流量变现服务及移动广告聚合工具时，移动应用开发者会在其移动应用中嵌入我们的SDK，我们会通过SDK获取用户个人数据；

（2） 当我们与程序化广告交易平台或流量供应商平台合作时，程序化广告交易平台或流量供应商平台向我们的需求方平台发送广告需求时，可能会与我们共享用户个人数据；

（3） 我们的广告主、广告需求方平台、程序化广告交易平台或其所使用的第三方归因平台会与我们分享用户个人数据；

TopOn服务的过程中，我们并不与用户建立直接联系，我们会通过TopOn的商业合作伙伴（如使用TopOn的SDK的移动应用开发者、程序化广告交易平台、广告聚合平台、广告需求方平台、流量供给方平台等）获取用户对个人数据收集和使用方面的授权同意。在我们与TopOn的商业合作伙伴的合作协议中，我们已要求他们承诺并保证数据来源的合法性，且他们会按照适用法律的要求向用户告知我们处理个人数据的具体情况，并取得用户的有效同意（必要时，获得适用法律要求的单独同意）并确保用户可以随时撤销这种同意。

TopOn服务可能会链接到第三方网站、应用程序或其他第三方内容。请注意，我们无法控制第三方对用户个人数据的处理，第三方的隐私保护规定可能与本隐私政策中描述的不同。

当我们收集合作伙伴业务代表的姓名和电子邮件地址等个人数据时，我们的目的是与他们进行业务沟通，包括履行我们与合作伙伴之间的合同所需的沟通。

（1） 根据您的要求签订或履行合同所必需的；

（2） 履行法定职责或者义务所必需的，例如与国家安全、国防安全以及犯罪侦查、起诉、审判和判决执行等直接相关的；

（3） 为应对突发公共卫生事件，或者紧急情况下保障自然人生命健康、财产安全所必需的；

（4） 为公共利益开展新闻报道、舆论监督等活动，在合理范围内处理个人数据；

（5） 在合理范围内处理您自行披露的个人信息，或其他已经合法披露的个人信息（例如通过合法的新闻报道、政府数据公开等渠道合法披露的个人信息）；

（6） 法律、法规规定的其他情形。

**特别提示：根据法律规定，如果数据无法单独或者与其他数据结合识别特定个人，则不属于个人数据。当您的数据能够单独或者与其他数据结合识别您本人，或者当我们将不与任何特定个人关联的数据与您的个人数据结合使用时，我们会按照本隐私政策的约定将其视为您的个人数据并进行保护。**

**如果您位于欧洲经济区，在必要时，我们会根据GDPR规定的“合法利益”使用您的个人数据。我们的合法利益包括：监控和防止欺诈、消除系统运行的技术障碍、确保系统和流程的正确和安全运行。**

**关于敏感个人信息**

**敏感个人信息是指一旦泄露或被非法利用，容易导致自然人的人格尊严受到侵犯、人身、财产安全受到危害的个人信息。敏感个人信息的范围可能因适用的不同数据保护法律而有所不同。**

**我们不会收集您的敏感个人信息。我们的业务合作伙伴在向您告知处理您的敏感个人信息的必要性以及对您的权益的影响并征得您的同意后，才会传输或授权我们处理您的敏感个人信息。**
