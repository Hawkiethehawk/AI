# 子账号管理

## 1. 功能概述

TopOn支持您授权其他成员查看或者管理您账户下的某个或者部分应用。

## 2. 操作指引

您可以按照以下步骤完成子账户授权。

(1) 点击【账号管理】-【子账号设置】



(2) 点击左上角【**+子账户】**进入设置页面

① 自定义输入**子账户名称**，支持0-30个字符。

② 子账号**登陆邮箱**输入。需要注意的是添加的子账户邮箱不能是在TopOn已注册的邮箱。

③ 输入**密码**。如密码遗失，请前往主账号重新设置密码。

④ 指定应用范围。全部即授权该子账户显示所有应用；指定应用即进一步下拉勾选部分应用。

⑤ 页面功能权限。您可以根据子账号的使用场景为子账号设置可查看的页面功能。

⑥ 自定义添加备注信息，非必填。



**快捷选项：**

可对页面功能权限进行快捷选择。

针对技术使用的账号，创建时可点击 快捷选项：技术，将默认仅选择SDK下载页面的权限。



**广告平台权限：**

因广告平台权限比较敏感，可根据具体场景配置权限

- 可单独选择【查看变现平台】权限，仅可查看广告平台配置
- 【编辑广告平台信息】：若需要更改广告平台配置的账号信息，例如是否开启报表API功能、修改密钥等
- 【修改广告平台状态】：控制开关广告平台账号状态，关闭广告平台账号会导致所有配置了这个广告平台的应用都关闭此广告平台的广告源，非必要勿开启
