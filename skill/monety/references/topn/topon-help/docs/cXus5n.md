# 广告源配置

## 1. **广告源的配置**

### 1.1 如何配置广告源

**(1) 选择应用和广告位**

**配置的广告平台ID须与选择的广告位样式一致**（如选择了激励视频广告类型，则配置的广告平台ID也为激励视频）。



#### **(2) 点击【添加广告源】-【添加单个广告源】**

选择对应的广告平台，按要求填写参数。



① 若是新添加的广告平台，需要先填写广告平台参数。

**通过截图中“如何找到这些参数？”指引可了解报表API参数获取路径。**

报表API仅用于拉取广告平台的报表数据（如收益API等），若暂时无法申请到报表API，可先选未开通，后续需要时再开通即可。



② 填写广告平台的代码位参数



| 配置项 | 说明 |
| --- | --- |
| 账号名称 | 如需切换广告平台账号，请前往广告源管理页面进行修改。 （***路径***：广告平台页面→广告源管理→选择需要修改的应用→右上角“编辑”。）[>>广告平台页面说明](/cn/docs/Zz3Bk5) |
| 广告源参数 | 通过截图中**“如何找到这些参数？”**指引可了解广告源参数获取路径，不同广告平台对应需要填写的参数叫法和内容不同，按要求填写即可。[>>广告平台配置指南](/cn/docs/A1g9gY) |
| 排序价格 | 该价格仅用于广告请求时的优先级排序：比如添加了ABCDE 5层广告源，需要对这5层广告源进行排序，这个排序会按照填写的价格从高到低排序，并不影响广告填充。  建议该价格与该广告源真实eCPM（即eCPM API）数值尽可能一致，可用于预估当天实时的收益和LTV。  ***注意***：若多个广告源的排序价格一样，则优先级默认一样，每次请求时随机优先级请求；到了展示的时候，可设置同价格广告源展示概率。  **排序价格填写小技巧**：  首先区分账号是否有三方广告平台的底价权限（一般三方广告平台对开放底价权限有流水要求，建议自行联系三方平台的AM确认是否有底价权限或者开通底价权限）。  ①如果有底价权限，则按照在三方平台设置的底价填写即可。  ②如果没有底价权限，则可以按照开发者自己的意愿进行配置，原因是TopOn后台的排序价格只会影响TopOn SDK在进行广告请求和展示的顺序。  举例，当穿山甲广告源A没有底价权限的时候，不论设置排序价格为1还是100，只要他的排序是所有其他广告源里面最高的，都会先请求穿山甲广告源A。这时候不论穿山甲平台返回任何价格的广告，即使穿山甲平台返回价格为0.01的广告，在实际广告展示的时候都会优先展示这个穿山甲广告源A。  这是因为在TopOn后台设置的排序价格只影响请求和展示时候的优先顺序。如开发者希望穿山甲第一个请求展示，优量汇第二个进行请求展示，只需要设置穿山甲的排序价格大于优量汇即可，如可设置穿山甲排序价格=2，优量汇排序价格=1。  注意：若没有三方平台的底价权限，或者在平台后台设置为无底价代码位，建议该代码位在在上线之前预估一个尽可能小于等于实际的均价，例如开屏2元或者直接填写一个0.01的价格，并打开自动价格功能。此操作是让无底价代码位尽可能地接近实际价格，并以预估的实际价格参与广告排序。 |
| 自动价格（可选） | 开启之后，TopOn会根据过去7天的平均eCPM来计算排序价格。 ***注意***：自动价格仅适用于已开通报表API的广告平台；该广告源累计展示量达2000次后正式生效，否则以手动填写的排序价格为准。 **如何判断自动价格是否需要打开**：开发者自行判断是否需要使用此功能。 ①对于已在三方后台设置底价的广告源来说，即使不打开自动价格，一般来说eCPM API=排序价格（建议这样配置）=广告平台设置的底价eCPM，所以是否打开影响不大。 ②对于没有三方底价权限、但是有三方广告平台API权限的开发者，可以打开自动价格获取该广告源的eCPM API，使TopOn SDK在请求和展示广告时更符合广告的实际eCPM价格，最大程度保证展示高eCPM的广告。 |
| 更多设置（可选） | ①展示上限（小时）：单个用户在1小时内可以观看该广告源广告的最大次数； ②展示上限（天）：单个用户在1天内可以观看该广告源广告的最大次数； ③展示间隔（秒）：单个用户本次该广告源展示到下次该广告源请求之间的时间间隔 ***注意***：展示频控均为本地设置，若卸载重装则限制重新计算；视频类展示间隔为视频播放开始与下次请求之间的时间间隔 |

### 1.2 常见问题

**(1) 没有报表API怎么办？**

报表API仅用于拉取广告平台的报表数据（如收益等），不影响应用正常展示广告和使用，若暂时无法申请到报表API，可先选未开通，后续需要时再开通即可。

***部分国内广告平台申请报表API有一定门槛（如穿山甲、优量汇、百度、快手），若暂时申请不到报表API，可暂时先手动上传。（路径：【TopOn开发者后台】-【高级功能】-【上传三方数据】）***



**(2) 什么情况下建议使用自动价格？**

① 因自动价格是根据前7天平均eCPM排序，有较大的延迟，因此在条件允许的情况一般不建议开发者打开自动价格而是选择手动调整。但若精力有限，且广告源的eCPM较为稳定，可以选择开启自动价格。

② 瀑布流（waterfall）底部的几层。

③ 广告源可打开自动价格，因为兜底的广告源调整频率较低且价值不高，可开启自动价格由其自行排序。

**(3) 什么情况下建议使用展示频控（展示上限/间隔）？**

**情景①：**某些广告平台无法设置底价时，通过控制展示频次提升单用户展示质量，间接提升eCPM。

**情景②：若集成Facebook和admob，在应用上线初期建议先设置一下展示频次上限，否则可能会因为个别极端设备导致广告平台账号封号。（路径：TopOn开发者后台-【聚合管理】-【添加广告源】-【添加单个广告源】-【更多设置】-【展示数上限】）**



## 2. **广告源优先级的调整**

产品上线后，需要根据数据表现来调整广告源优先级，进一步提高广告变现收益。

### 2.1 如何调整优先级

(1) 通过调整排序价格或者拖拽广告源手动调整；waterfall按照价格从高到低排序。



(2) 通过开启自动价格系统自动排序；TopOn会自动根据历史7天的数据计算eCPM并调整排序；需注意的是，广告源累计展示量大于等于2000时自动价格才会正式生效。编辑广告源时可开启自动价格。



### **2.2 同价格广告源优先展示概率配置**

#### **2.2.1 什么是同价格广告源优先展示概率？**

**(1) 广告源优先级右侧的百分比是同价格广告优先展示概率。您可以通过设置广告源的优先展示权重来调整优先展示概率。**

**(2) 使用同价格广告源优先展示概率，您需要更新TopOn SDK v5.7.61 及以上版本。**

**(3) 您可以为各个同价广告源独立设置优先展示概率。**当同价格的广告源有多个广告源填充了广告时，TopOn会按您设置的优先展示概率选择本次展示的广告源。

#### **2.2.2 如何配置同价格广告源的优先展示概率？**

(1) 在聚合管理列表中同价格广告源的优先级右侧会出现优先展示概率，如下图：



(2) 开发者可以通过广告源优先级右侧的编辑入口，设置同价格广告源的优先展示**权重**

(3) TopOn会根据您设置的**权重**自动计算出同价格广告源的优先展示概率。

**小建议：如果开发者想更加直观的调整展示概率，建议开发者按全部同价广告源权重之和为100来分配各个广告源的权重。**

## 3. 兜底广告

### 3.1 什么是兜底广告

**TopOn侧的兜底广告是TopOn针对特定广告场景的收益提升方案**。**建议使用三方平台无底价广告位配置兜底广告**。兜底广告源能作为有效的收益补充方案，解决部分广告场景填充率偏低的问题，保障了应用和广告位的收益，精简广告源配置和及运营方案，同时降低了运营维护成本。

### 3.2 如何使用兜底广告

**TopOn已支持兜底广告的广告形式，在对应广告位创建广告源时，在配置界面开启“兜底广告”即可。**

- **路径1：【**TopOn后台】-【聚合管理】-【添加广告源】-【添加单个广告源】-【兜底广告】
- **路径2：【**TopOn后台】-【广告平台】-【变现平台】-【广告源管理】-【添加广告源】-【添加单个广告源】-【兜底广告】





### 3.3 兜底广告的广告请求和展示逻辑

- **广告请求：**在瀑布流请求发起后，兜底会并行于Waterfall发起。如果存在多个兜底广告源，兜底广告源将按指定顺序串行请求。兜底广告通过错峰并行策略，能够充分利用网络资源请求和加载广告，缩短广告的填充耗时，进而减少用户等待广告加载的时间，提高了用户体验
- **广告展示：**当瀑布流请求没有填充时，TopOn将使用兜底广告展示。当瀑布流请求有填充时，TopOn按高价进行展示。

**PS：**

- 注意这里的兜底广告不同于常见的瀑布流【兜底广告】。通常意义上的瀑布流【兜底广告】为：设置无底价广告或者价格较低的广告，并配置于瀑布流最底层，作为瀑布流的兜底，保证广告位的整体流量填充率。如：创建一个Mintegral的广告并设置该广告位底价为0.1人民币，并对应配置在TopOn聚合管理。
- 在TopOn侧设置兜底广告源能提升整体广告位的填充率。原因是，类似于增加了并行请求的广告源数量，也就是获得广告填充的几率增加了，在展示广告的时候，有广告填充提供展示的几率增加了。但是对于单个用户或者单个设备来说，依然有可能没有广告填充，这是由于广告平台对用户流量价值的评估不同，广告平台在真实匹配广告的时候会根据自身的用户画像和预算情况决定是否对单个用户进行广告填充。并不是设置了兜底广告以后，用户就能100%获得广告填充和展示。
- TopOn SDK v5.7.94 及以上版本开始支持兜底广告。

### **3.4 针对开屏广告TopOn提供安装首次开屏广告展示超时的优化方案**

(1) 在开屏广告位上创建**SDK预置策略**的流量分组。

(2) 在**SDK预置策略**配置瀑布流，同时建议您增加一个**兜底广告源。**

(3) **导出SDK预置策略**并预置到应用中。

具体操作流程参考 [《SDK预置策略使用说明》](/cn/docs/wERYJv)

这样配置的效果：**可以实现SDK预置开屏策略，同时实现开屏兜底广告源的兜底功能**。即：此兜底广告源会和广告位下的整体瀑布流并行发起请求。并且用户不会在首次请求时必定使用兜底广告，而是正常走瀑布流和兜底广告源的并行请求。可以实现变现价值最大化。

此方案适用于全部广告类型，TopOn SDK>= v6.1.78支持。

## 4. 自动创建广告源

开发者配置广告源的一般流程为：在三方广告后台创建广告位后，再在TopOn后台创建并填入参数信息。过程相对复杂，且较易出错。为方便开发者快速配置广告源，TopOn提供自动创建广告源功能。

开启该功能后，当您在TopOn后台创建广告源时，TopOn会自动在三方广告后台申请创建广告位，并将相关的参数信息回填到TopOn上。您无需在三方广告后台进行手动创建。

### 4.4 如何在各平台配置及使用

#### ● Mintegral

(1) 在开通报表API权限后，自动创建广告源处选是，填入密钥即可完成授权。



(2) 如果自动添加广告源报错时，请确定您的Mintegral账号是否已开通创建媒体&广告单元接口。



(3) 如果已开通创建媒体&广告单元接口权限但还是报错，建议您在Mintegral后台针对此App，修改聚合平台为TopOn。



#### ● 腾讯广告

(1) 在开通报表API权限后，自动创建广告源处选是，填写账户ID和Secret Key后保存，将自动校验当前账户是否有创建广告位权限。



(2) 在瀑布流新建广告位时，若您已完成上述步骤，即可见到自动创建广告源的选项，选是，可选择竞价或非竞价广告源创建，录入相关信息，即可完成创建。

## 5. 智能粘贴导入

批量添加广告源时，可选择智能粘贴导入功能。

支持直接将三方广告平台导出的excel表格内容直接粘贴识别。可将三方广告平台的广告位ID、广告位名称、排序价格粘贴到输入框，输入完成后点击识别按钮，自动识别输入的内容，并智能识别对应的广告平台，仅支持部分广告平台。

### **5.1 目前支持自动识别的广告平台**

穿山甲、优量汇、快手、Mintegral、Sigmob，其他广告平台ID导入时需要手动选择广告平台。

### **5.2 具体页面步骤**

**(1) 【聚合管理】-【添加广告源】-【批量添加广告源】，添加广告源入口新增【+智能粘贴导入】入口，点击可打开导入弹窗。**



**(2) 导入弹窗页面可按照图示步骤进行智能识别：**

① 将三方广告平台导出的excel表格的广告位ID、广告位名称及需要设置的排序价格分别粘贴到三方广告平台信息输入框，广告位名称及排序价格可留空

② 输入完成后点击识别按钮

③ 识别信息处将显示智能识别对应的广告平台，确认信息后点击一键导入即可导入到对应广告平台配置下，未输入广告平台则导入到当前广告平台。

**注意**：若当前广告位未关联导入的平台，将无法在广告平台处选择对应平台，需要在批量添加页面或广告平台页面先进行关联。



## 6. 批量添加/编辑广告源

当需要针对该广告位下多个流量分组的广告源进行调整时，可通过批量添加/编辑广告源功能实现，在聚合管理点击批量添加/编辑广告源入口进入页面。

**(1) 批量添加：**点击【+广告源】按钮增加新广告源，默认在所有流量分组都新增，可通过开关关闭不需要新增的流量分组，流量分组可筛选显示。可对各个流量分组单独设置排序价格等数据。





**(2) 批量编辑：**显示当前广告源已绑定的所有流量分组，可针对单个广告源绑定的不同流量分组进行编辑（开启/关闭，解绑），可编辑各个排序价格，流量分组筛选显示



## 7. 批量复制广告源

(1) 当该waterfall所属的广告位有多个流量分组或打开AB测试时，可通过复制广告源功能批量复制该广告位下其他分组的waterfall，多个流量分组可直接使用相同的广告源。



(2) 选择需要复制的分组，勾选需要复制的广告源，将广告源的eCPM价格、开启状态、广告源策略（展示次数限制等）等该广告源所有设置复制到当前分组。



## 8. 常见问题

**(1) 在TopOn后台修改了配置，多久会生效？**

topon后台所有的配置都基本遵循这个时间：topon后台调整5分钟后，即生效。

若需要测试，则请将手机时间往后调1小时再试试；或者 安卓清理缓存/IOS卸载重装 再试试。（因为策略缓存时间大概为半小时）

特别地， 流量分组中的自定义规则是动态调整的，若自定义规则已修改，则会在下一次的广告请求时更新至最新的流量分组规则。

**(2) 聚合管理中，广告平台 Bidding 是采用服务端 Bidding 还是客户端 Bidding，是否需要开发者做技术联调？**

部分广告平台采用服务端 Bidding，部分广告平台采用客户端 Bidding，详细信息可见：[>>聚合平台概况](/cn/docs/2KR6QU)

不需要开发者做技术联调，应用端只需要集成对应版本的 TopOn SDK，然后填写 Bidding 广告位即可。
