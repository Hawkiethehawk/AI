# TopOn聚合介绍

## **1. 产品介绍**

TopOn是全球领先的移动广告聚合工具平台，专注于为全球移动开发者提供广告变现运营管理及优化服务。

在TopOn基于大数据打造的智能化聚合管理工具中，您可以：

- 一站式对接海内外多家广告平台SDK，降低聚合广告变现门槛；
- 借助TopOn智能强大的流量分配策略，快实施精细化运营策略，最大化广告变现收益；
- 通过多维度数据报表，精准比对广告平台API数据，助力开发者实现广告收益最大化。

目前TopOn已合作客户数量 10000家+，合作产品数量 30000款+，日广告请求 300亿。

## **2. 产品优势**

### 2.1 海量广告资源

TopOn聚合了全球海量的广告平台，支持多样化的广告样式，提供多种类引擎支持，降低您聚合广告变现的门槛。

### 2.2 业内首创：便捷的广告调试模式

为方便开发者对自己的广告集成情况进行测试和验证，TopOn提供了调试模式（DebuggerConfig）。您可以在自己的项目中调用API，配置测试所需的信息，使用TopOn预先为各个广告平台配置的测试广告源，进行各种广告行为，然后通过日志输出来定位广告集成中存在的问题。

调试模式支持多数平台非竞价广告源和部分平台竞价广告源的测试，覆盖主流广告平台，不受本地缓存策略的影响，无延迟，使用便捷性很高。

### 2.3 精细化运营功能

**(1) 流量分组：**支持多个维度对用户进行分组，不同的流量分组可以配置不同的Waterfall，以实现精细化流量变现的目的。

**(2) Bidding：**支持多个广告平台的实时公开竞价，将传统Waterfall与In App Bidding的有效结合，实现更智能、高效、透明的广告变现方式。

**(3) 新A/B测试：**支持将用户按比例分为对照组和测试组并对不同的组使用不同的配置。您可以通过对两组分别使用不同的广告策略并对比结果，来帮助您验证哪种广告策略效果更好。

**(4) 交叉推广：**通过交叉推广功能，可实现不同产品之间的互相推荐导流。TopOn同时支持直投广告功能，帮助APP媒体具备直客广告管理及运营能力，广告主投放预算即广告变现收入所得，进一步突破广告收益天花板，储备独立商业化运作的技术和运营能力。

**(5) 展示频次控制：**TopOn支持**【广告位】**维度和**【广告源】**维度2种展示频次控制功能，通过该功能您可以限制低价值广告源展示次数，提高高价值广告源的展示占比。

### 2.4 全面详尽的数据报表

TopOn提供了丰富的广告变现侧的数据维度，以全面了解您的广告业务变现效果。数据报表包含：综合报表、留存价值报表、用户行为报表、分小时报表、交叉推广报表、ROI报表等多维度的可视化内容。

### 2.5 Open API

TopOn Open API支持开发者后台管理、数据报表查询，提供设备维度数据报告的API接口等，提高开发者变现效率。
