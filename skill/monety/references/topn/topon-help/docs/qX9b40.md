# 日志分析

## 1. 功能概述

TopOn提供**广告位、广告源**的**请求失败、展示失败、竞价失败**的日志分析，您可以通过日志分析功能协助排查问题。日志分析数据支持查询最近14天。



① 日志分析功能支持以下维度：

| 日志类型 | 日志维度 | 必选数据维度 | 说明 |
| --- | --- | --- | --- |
| 竞价失败 | 广告位 | 广告位 | 分析广告位下全部竞价广告源竞价失败日志 |
| 请求失败 | 广告位 | 广告位 | 分析广告位的请求失败日志(对应广告位**流量请求不填充**的原因） |
| 展示失败 | 广告位 | 广告位 | 分析广告位的展示失败日志 |
| 竞价失败 | 广告源 | 广告源 或 广告平台 | 分析广告源的竞价失败日志(对应广告源**竞价不响应**的原因） |
| 请求失败 | 广告源 | 广告源 或 广告平台 | 分析广告源的请求失败日志(对应广告源**广告请求不填充**的原因） |
| 展示失败 | 广告源 | 广告源 或 广告平台 | 分析**激励视频、插屏**广告源的视频播放失败日志 |

② 日志分析可以查询当天的数据

## 2. 操作指引

### 2.1 广告位&广告源的竞价失败

(1) 分析广告位的**竞价失败**日志时，当您选择需要分析的**广告位** 、**广告平台**、 **广告源**后，TopOn会输出相应的日志内容。



| 指标 | 说明 |
| --- | --- |
| TopOn错误代码 | TopOn SDK内部统计的错误代码 |
| TopOn错误类型 | TopOn SDK内部统计的错误类型 |
| TopOn错误信息 | TopOn SDK内部统计的错误信息 |

(2) 您可以根据TopOn SDK的错误类型定位**广告位** 、**广告平台**、 **广告源**竞价无填充的原因

| TopOn错误代码 | TopOn错误类型 |
| --- | --- |
| -1 | 竞价失败 或 广告平台不出价 |
| -2 | 广告平台SDK未完成初始化，无法发起竞价请求 |
| -3 | 网络超时 |
| -4 | TopOn S2S接口异常 |
| -5 | 由于广告源的展示上限限制，不参与本次竞价请求 |
| -6 | 由于广告源的展示间隔限制，不参与本次竞价请求 |
| -7 | 由于“竞价失败后下次竞价时间间隔”原因限制，不参与本次竞价请求 |
| -8 | 由于“开发者通过SDK API传入过滤广告源ID”原因，不参与本次竞价请求 |
| -9 | 由于“集成异常(广告平台SDK不存在、adapter不存在)”原因，不参与本次竞价请求 |

### 2.2 广告位请求失败

(1) 分析广告位的**请求失败**日志时，当您选择需要分析的**广告位**后，TopOn会输出相应的日志内容。



(2) 广告位的请求失败原因，具体输出内容如下：



| 指标 | 说明 |
| --- | --- |
| TopOn错误代码 | TopOn SDK内部统计的错误代码 |
| TopOn错误信息 | TopOn SDK内部统计的错误信息 |

(3) 您可以根据TopOn SDK的错误代码定位广告位无填充的原因。

[TopOn Android SDK错误代码说明](/cn/docs/qYfOSS)

[TopOn iOS SDK错误代码说明](/cn/docs/cuo-wu-ma-shuo-ming)

### 2.3 广告位展示失败

(1) 分析广告位的**展示失败**日志时，当您选择需要分析的**广告位**后，TopOn会输出相应的日志内容。



(2) 广告位的展示失败原因，具体输出内容如下：



| 指标 | 说明 |
| --- | --- |
| TopOn错误代码 | TopOn SDK内部统计的错误代码 |
| TopOn错误信息 | TopOn SDK内部统计的错误信息 |

(3) 您可以根据TopOn SDK的错误代码定位广告位展示失败的原因。

| TopOn错误代码 | 说明 |
| --- | --- |
| 1 | **当前没有可展示的广告源。**可考虑提前预加载广告或增加广告加载场景 |
| 2 | **被广告位的展示上限限制。**可考虑修改广告位的展示上限设置 |
| 3 | **被广告位的展示间隔限制。**可考虑修改广告位的展示间隔设置 |
| 4 | **当前策略为空。**在广告位还没有加载到WaterFall策略之前，App调用展示广告会上报此错误 |

### 2.4 广告源请求失败

(1) 分析广告源的**请求失败**日志时，当您选择需要分析的**广告源** 或 **广告平台**后，TopOn会输出相应的日志内容。



(2) 广告源的请求失败原因，具体输出内容如下：



| 指标 | 说明 |
| --- | --- |
| TopOn无填充类型 | TopOn SDK内部统计的无填充类型 |
| 广告平台错误代码 | TopOn SDK记录到广告平台返回的错误代码 |
| 广告平台错误信息 | TopOn SDK记录到广告平台返回的错误信息 |

(3) 您可以根据TopOn SDK的无填充类型定位广告源无填充的原因

| TopOn无填充类型 | 说明 |
| --- | --- |
| 0 | **广告源无填充。** 需要根据**广告平台错误代码**和**广告平台错误信息**排查 |
| 1 | **广告源填充超时**。广告源在15分钟内未返回填充结果 |
| 2 | **被广告源的展示上限限制。**可考虑修改广告源的展示上限设置 |
| 3 | **被广告源的展示间隔限制。**可考虑修改广告源的展示间隔设置 |
| 4 | **上次无填充，在指定时间内不发起请求。**可联系TopOn进行设置 |
| 5 | **命中在Load方法中传入的过滤广告源ID**，本次不发起请求 |
| 6 | **竞价广告源的Bid Token已失效**，本次不发起请求 |
| 7 | **当前广告源正在展示**，本次不发起请求 |

(4) 您可以根据**广告平台错误代码**和**广告平台错误信息**定位广告源无填充的原因：

[广告平台 Android 错误代码说明](/cn/docs/qYfOSS#2._%E7%AC%AC%E4%B8%89%E6%96%B9%E5%B9%BF%E5%91%8A%E5%B9%B3%E5%8F%B0%E9%94%99%E8%AF%AF%E7%A0%81)

[广告平台 iOS 错误代码说明](/cn/docs/cuo-wu-ma-shuo-ming)
