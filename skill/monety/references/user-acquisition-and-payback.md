## 回收判据和漏斗

净 LTV = IAA LTV + IAP LTV - 退款、税费和其他损耗

CAC = 投放花费 / 有效新增用户

ROAS = 已回收收入 / 投放花费

结论必须注明观察周期。短期 ROAS 不能替代完整 LTV，也不能忽略现金流、退款和留存。

买量漏斗：

预算 → 展示 → 点击 → 商店页访问 → 安装 → 首次打开 → 核心任务 → 广告或付费触点 → IAA/IAP 收入 → 留存与回收

沿漏斗定位，不把单个阶段的高转化当作最终成功。

## 成本、质量和事件

低 CPI 只说明安装便宜，不能说明用户能够回收。判断顺序是 CPI、激活成本、广告和付费收入、留存、净 LTV、ROAS。

安装增加但收入不涨时，检查地区与渠道结构、素材承诺、版本、核心任务、广告事件和付费事件，不要只调整出价。

事件按深度分层：

| 层级 | 示例 | 用途 |
|:---:|:---|:---|
| 浅层 | 安装、首次打开、新手完成 | 提供数量足够的激活信号 |
| 中层 | 核心任务完成、广告场景、付费墙展示 | 表示进入价值和变现路径 |
| 深层 | 广告收入、试用、购买、续订、退款 | 校准真实商业价值 |

浅层事件量大但离收入远，深层事件价值高但量少。Google、Meta 和 TikTok 的公开资料都把安装、应用内事件或价值优化区分为不同目标，分别参照 **[UA-GOOGLE-01-关于应用广告系列]** **[UA-META-01-Meta 应用推广目标]** **[UA-TIKTOK-02-TikTok 应用推广目标]**。用量足够的代理事件优化，同时用收入事件校准。

## 归因与隐私

归因至少保留媒体、活动、广告组、素材、地区、平台和优化事件。命名稳定、可解析，变更时保留历史映射。

归因系统服务于优化，不等于财务结算。投放、归因、商业化和财务数据不一致时，核对窗口、时区、币种、去重和收入确认。

iOS 隐私归因通常具有聚合和延迟特征：不做分钟级调整，不假设能恢复单用户完整路径；选择早期产生且与长期价值相关的信号。

## 素材、首体验和 ROAS

素材吸引目标用户，商店页承接承诺，首体验完成价值验证。

| 现象 | 优先检查 |
|:---:|:---|
| 点击高、安装低 | 素材与商店页是否一致 |
| 安装高、激活低 | 承诺是否匹配产品，新手流程是否阻塞 |
| 激活高、收入低 | 广告场景、付费墙和事件是否到达 |
| 收入高、留存低 | 是否过度变现、误导或牺牲核心任务 |

评价素材看用户 LTV，不只看点击率。

ROAS 下降拆成两侧：

- 成本上升：展示或点击价格、竞争、流量结构、出价策略。
- LTV 下降：激活、广告展示或 eCPM、付费转化或续订、留存。

短期高 ROAS 要先排除归因窗口、收入确认、小样本、自然量和留存影响，再决定放量。

## 运营与放量

每日检查花费、安装、激活成本、早期广告和付费收入、核心任务和事件异常；按地区、平台、活动和素材拆分。

每周检查队列 LTV、回收周期、素材疲劳、渠道结构、商店页转化，以及投放、归因、商业化和结算口径差异。

放量前确认：

1. 归因命名统一，关键维度完整。
2. 核心任务、商业化触点和收入事件正常回传。
3. ROI 按用户队列计算，不与自然日收入混算。
4. 已定义预算停止条件和异常回退方式。
5. 留存、退款和核心任务完成率作为护栏。
