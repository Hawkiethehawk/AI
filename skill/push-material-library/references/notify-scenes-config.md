# NotifyScenesConfig 字段速查

来源：《NotifyScenesConfig运营配置手册 v2.0》，docx token `<MANUAL_DOCX_TOKEN>`；模板表与全局参数来自文档内嵌电子表格 `<SHEET_TOKEN>`。

## 使用方式

1. 按手册写标准 JSON。
2. 整段 JSON 转 Base64。
3. 写入 `ol_notify_b64_config`。

未配置的场景默认关闭。

## 场景键（顶层对象）

| Key | 场景 | 触发时机 |
|-|-|-|
| `ul` | 解锁 | 用户完成屏幕解锁 |
| `ta` | 定时 | 按 `cd` 或 `cdt` 周期触发 |
| `ab` | 切后台 | App 进入后台约 5 秒后 |
| `pkg` | 应用变化 | 其他 App 安装、更新或卸载 |
| `wifi` | Wi-Fi 变化 | Wi-Fi 连接或断开 |
| `rq` | 截图（需文件管理权限） | 检测到新截图 |
| `dc` | 充电/电量 | 充电状态切换或电量下降跨过阈值 |
| `file` | 文件变动（需文件管理权限） | 手机文件新增和删除 |
| `app` | 占位场景 | 宿主触发，通知 SDK 不主动触发 |

## 场景参数

| 参数 | 类型 | 默认 | 含义 |
|-|-|-|-|
| `sts` | Int | 0 | 场景开关：0 关、1 开 |
| `cd` | Int | 0 | 同场景最小展示间隔（秒），0 不限制 |
| `cdt` | String | "" | 分时段间隔，命中时覆盖 `cd` |
| `dly` | Int | 0 | App 安装多少秒后才允许展示 |
| `org_dly` | Int | 0 | 自然量用户的额外安装时长门槛，-1 = 自然量不展示 |
| `vip` | Int | 0 | 0 允许展示、1 VIP 不展示 |
| `dcm` | Int | 0 | 场景每日最多首次展示数，0 不限制 |
| `levels` | String | "" | `dc` 电量阈值，如 `"80,60,30"` |
| `lt_sts` | Int | 0 | 场景重发开关：0 关、1 开 |
| `display_type` | Int | 0 | 0 有悬浮窗权限走悬浮窗否则通知、1 仅通知、2 仅悬浮窗；其他值按 0 处理 |
| `temps` | Array | [] | 场景的通知模板列表 |

`cdt` 写法：`"23:00-06:00:-1;06:00-23:00:30"`，多段英文分号分隔，`-1` 表示该时段不展示，未命中任何时段时回退 `cd`，时间用 `HH:mm`。

## 模板参数（temps 内）

| 参数 | 类型 | 默认 | 含义 |
|-|-|-|-|
| `tempId` | Int | 0 | 模板 ID，必须是当前 App 版本已注册的 ID |
| `wgt` | Int | 0 | 权重，必须大于 0；同组合计建议 100 |
| `content` | String | "" | 主文案，是否生效由模板决定，支持富文本 |
| `btnText` | String | "" | 按钮文案，是否生效由模板决定 |
| `contentId` | Int | 0 | 内容 ID，用于展示与点击统计 |
| `autoCancel` | Boolean | true | 点击通知后是否自动取消 |
| `ongoing` | Boolean | false | 是否常驻通知 |
| `cx` | Int | 0 | 通知关闭按钮：0 隐藏、1 显示、2 仅非自然量显示 |
| `cxRate` | Int | 0（260916 起默认 100） | 点关闭后只关闭不跳转的概率 0~100，自然量固定 100 |
| `subType` | Int | 0 | 子场景类型，0 = 通用 |
| `lt` | Int | 0 | 重发总次数，仅场景 `lt_sts=1` 时生效 |
| `imageList` | Array<String> | [] | 在线图片 URL 列表，数量与顺序由模板决定 |
| `overlayCx` | Int | 1 | 悬浮窗关闭按钮：0 隐藏、1 显示、2 仅非自然量显示 |
| `overlayCxRate` | Int | 100 | 悬浮窗点关闭后只关闭不跳转的概率 0~100，自然量固定 100 |

## 子场景 subType 与推荐模板

| 场景 | subType 含义 | 推荐模板 |
|-|-|-|
| `ul` | 0 通用 | 901（文）、906（图）、940、920 |
| `ta` | 0 通用 | 901（文）、906（图）；高概率 940，低概率 920、904、905 |
| `ab` | 0 未区分、1 广告点击切后台、2 新手流程中断 | 901、902、903（文字）、906（图片） |
| `pkg` | 1 安装/更新、2 卸载 | 901、902、903（文字） |
| `wifi` | 1 连接、2 断开 | 901（文）、906（图）、920 |
| `rq` | 0 通用 | 901（文）、940 |
| `dc` | 1 接入充电、2 断开充电、3 起依次对应 `levels` | 901（文）、906（图） |
| `file` | 1 新增文件、2 删除文件 | 907 |

模板选择规则：触发 `subType=0` 且存在 0 号模板时只从 0 号模板抽取；不存在时从全部模板按 `wgt` 抽取；触发非 0 时优先精确匹配，找不到再回退 0 号。匹配组内按 `wgt` 随机。精确 subType 已配置但权重全为 0 时，不回退通用模板，本次不展示。

`dc` 电量阈值：`levels: "80,60,30"` 时，接入充电 subType 1、断开 2、跨 80% 为 3、跨 60% 为 4、跨 30% 为 5；顺序决定编号，一次跨多个阈值取最低值阈值。

## 全局参数（参数表 `zDd21y`）

| 参数 | 说明 |
|-|-|
| `ol_notify_b64_config` | 本手册的运营配置，Base64 后的场景 JSON |
| `ol_notify_video_cfg` | 视频通知列表，字段 `contentId`、`title`、`content`、`imageUrl`、`videoUrl` |
| `notify_preload_time` | 单位秒，默认 60 |
| `notify_all_cd` | 单位毫秒，默认 5000 |
| `notify_all_dcm` | 全局弹出总日限，默认 -1 不限制；配置正整数时优先于其他场景规则拦截 |
| `notify_remove_pkg` | 包名黑名单，配置后屏蔽这些包名触发的通知，如 `["ggg","sss"]` |

## 重发规则

- 需同时配置场景 `lt_sts=1` 与模板 `lt`，如 `lt=4` 表示首次展示后每隔 4 秒重发一次共 4 次。
- 重发不受频控、单场景日限与总日限拦截，也不计入次数。
- 全局只保留最新一条重发任务，新任务取消上一条；原通知不在通知栏或 App 进程结束时停止重发。

## 固定规则

- App 前台、屏幕未亮、无通知权限时不展示。
- `rq` 仅支持 Android 11 及以上且需“所有文件访问权限”。
- Wi-Fi 快速切换受 2 秒去重限制，通常只保留最先到达的事件。
